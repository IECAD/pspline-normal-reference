# Location-specific P-spline normal references — code, primary outputs and registrations

This repository accompanies the manuscript

> A. Lim and J. H. Cho, *Location-Specific P-Spline Normal References for Sensor Anomaly Detection with Incomplete Training Data*, submitted to *Mathematics* (MDPI), manuscript mathematics-4658477, first revision.

It contains the code for every analysis on public data, the configurations, the primary outputs behind the tables and figures, and the pre-registration documents with their amendments. [`REGISTRATIONS.md`](REGISTRATIONS.md) gives the chronology of every registration and how to check the recorded SHA-256 fingerprints.

## What is not included

- **D1 (in-house UWB data, three rooms).** The measurements and their loader are not public; they are available from the authors on reasonable request. `src/data/d1.py` is a stub, and the D1 part of the configuration (anchor coordinates, file list) is withheld. Analyses on D1 cannot be re-run from this repository, but their primary outputs (metrics per room, scenario and seed) are under `results/`.
- **Positioning experiments** (internal Experiments 2, 5 and 7) belong to a separate manuscript and are not part of this package.
- **Third-party data.** Download them from the original sources (below) into `data_ext/`.
- **Large score arrays** (`*.npz`, about 40 MB each) and intermediate caches. They are regenerated by the scripts.

## Layout

| Folder | Content |
|---|---|
| `src/` | Data loaders (`data/`), the normal-surface bank and P-spline fit (`model/`), comparators (`baselines/`), metrics (`metrics/`) |
| `experiments/` | One script per experiment (see the table below); `node_model_eval.py` holds the shared fit-calibrate-score path |
| `analysis/` | Figures, tables, cluster bootstrap, prediction variance, data checks; `analysis/out/` has their text outputs |
| `configs/` | Data and experiment settings |
| `results/` | Primary outputs: metrics per evaluation unit, scenario and seed; summaries; selections |
| `doc/` | Registration documents in their original language (Korean), unedited; `doc/registered/` holds read-only copies made at registration |
| `data_ext/*/` | Notes on the downloaded data (`STRUCTURE.md`: values seen before registration) |

Downloaded files are treated as untrusted: pickles are read with a restricted opcode parser (`src/data/safe_pickle.py`), and no code shipped with the datasets is executed.

## Environment

Python 3.10.11 on Windows 11; packages in `requirements.txt` (deep comparators use PyTorch with CUDA 12.6). Scripts set single-threaded BLAS. Run everything from the repository root.

## Preparing windows

```
python -m src.data.build --dataset d2      # D2 windows  -> cache/windows/d2/
python -m src.data.build --dataset d4      # SMD, ASD    -> cache/windows/d4/
python -m src.data.d6                      # D6          -> cache/windows/d6/
python -m src.data.d8                      # HYMN        -> cache/windows/d8/
python analysis/49_phy_loss_library.py     # D5 real packet-loss library -> cache/phy_loss_blocks.npz
python analysis/42_d2_nlos_signature.py    # D2 NLOS signatures for multi-metric injection
```
The Wi-Fi loader (`src/data/d7_uji.py`) reads the extracted CSVs directly.

## Registrations

Every experiment was registered in writing before it was run; results were appended to the same document afterwards, never edited above. Post-hoc or exploratory additions are marked as such in the documents. [`REGISTRATIONS.md`](REGISTRATIONS.md) lists them in time order, with what was seen before each, and explains how the fingerprints recorded for the revision can be checked against the files here.
