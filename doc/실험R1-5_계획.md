# 실험 R1-5 계획: 시뮬레이션 연구 (사전 등록, 2026-10-28)

작성: 2026-10-28 · 상위: `paper/mathematics/revision_r1/심사의견_정리.md`(결정 D4), `지적별_대응_초안.md` · 대응 의견: **C2·C4(주)**, A1·A4·C7(보조) · 대상: 이 저장소에서 작업하는 사람과 AI 어시스턴트

번호: 실험 11–13 은 Sensors 원고 계획이 쓰므로 Mathematics 1차 수정 실험은 R1-n 으로 부른다.

## 0. 목적
- 심사자 C 는 실데이터 섭동만으로는 부족하다며, 표본 크기·곡면 평활도·결측 기제·이상 특성·학습 오염·heavy-tail 오차를 통제해 바꾸는 시뮬레이션을 요구했다(C2·C4).
- 같은 설계로 세 가지를 함께 본다. (i) 빈 칸 예측 오차 식(A1 에서 새로 유도할 식)의 수치 확인, (ii) 견고 추정과 평활의 효과 분리(A4), (iii) 칸·그룹 수준 오경보율과 보정(C7, A 추가 4).
- 판정은 미리 정한 예측과 규칙으로 한다. 결과가 예측과 달라도 그대로 보고한다.

## 1. 생성 모형
한 반복 = 단위(방) 하나 = 노드 M = 12개. 노드마다 행 S = 4, 시점 T = 12. 잡음 척도 σ = 1 을 기준으로 한다.

- **정상 곡면:** m_{j,s}(t) = a_{j,s} + A · f_{s}(t; L) + b_{j,s}(t; L).
  - a_{j,s} ~ N(0, 2²): 노드·행별 수준(위치 의존). 노드마다 다르다.
  - f_s(t; L): 행별 공통 모양. b_{j,s}: 노드별 모양 변이(진폭 0.3·A, 같은 평활도 L).
  - **평활도 L:** L0 평탄(f = b = 0, D1 같은 정지 측정) / L1 매끄러움(한 창에 사인 1주기, 위상 무작위) / L2 거칢(주파수 1–4 주기 사인 합, 진폭 1/k). 진폭 A = 2.
- **잡음 ε:** G 가우스 N(0, 1) / T3 t₃(척도는 MAD 가 G 와 같도록) / CN 오염 정규 0.95·N(0, 1) + 0.05·N(0, 10²).
- **창 수(표본 크기):** 노드당 학습 N ∈ {3, 5, 10, 20}, 검증 5, 테스트 5.
- **학습 결측(학습 창에만, 검증·테스트는 그대로 — 실험 6 과 같음):**
  - MCAR: 칸마다 독립 확률 r ∈ {0, 0.3, 0.5, 0.7}.
  - BURST: Gilbert–Elliott, 평균 손실 π = 0.5, 평균 길이 L_b = 4 (`exp6_missing_patterns.py` 와 같은 식).
  - MNAR(값 의존): 노드·행의 참값 아래 30 % 분위보다 작은 관측은 확률 0.7, 나머지는 0.2 로 빠진다(전체 약 35 %). Wi-Fi 의 '약한 신호가 빠짐'을 흉내 낸다.
- **학습 오염:** 학습 창의 비율 p ∈ {0, 0.1, 0.3} 에 아래 이상을 라벨 없이 넣는다.
- **이상(검증·테스트 창):** 창마다 확률 0.5 로 행 하나에 넣는다. 유형: spike(1–2 시점), shift(창 전체), drift(0 에서 Δ 까지 선형). 크기 Δ ∈ {1, 2, 3}·σ. 기본은 세 유형을 같은 비율로 섞고 Δ = 2.

## 2. 비교하는 참조(모두 같은 점수·보정 경로)
| 기호 | 참조 | 구현 |
|---|---|---|
| CG | 셀 평균, 빈 칸 = 단위 전체의 행 평균(**현행 구현**) | `NormalSurfaceBank(time_basis="cell")` + Composer S1 표준화 그대로 |
| CF | 셀 평균 + 노드 행 평균 채움 | `time_basis="cellfill"` |
| CI | 셀 평균 + 선형 보간 | `time_basis="cellinterp"` |
| CMI | 칸별 **중앙값** + 선형 보간 | 새로 구현(칸별 중앙값, 빈 칸 보간) |
| NM | 노드 평균(d = 1, λ → ∞ 극한) | `time_basis="const"` |
| NMed | 노드 **중앙값** | 새로 구현 |
| PS | P-spline, d = 2, K = T, SAP | 제안 모델(원고와 같음) |
| PS1 | P-spline, d = 1 | |
| PSH | Huber P-spline, d = 2 (δ = 1.345, 바깥 반복 ≤ 5) | `robust="huber"` |
| PS1H | Huber P-spline, d = 1 | |

점수 A = |R − μ_s| / σ_s (μ_s, σ_s 는 검증 잔차), 임계 = 검증 칸 97.5 백분위. 참조마다 조정할 매개변수는 없다(선택 단계 없음).

## 3. 지표
- **M1 (주):** 테스트 셀 AUC-PR.
- **M2:** 참조 오차 RMSE(m̂ − m) — 학습에서 관측된 칸과 빈 칸을 나눠서.
- **M3:** 보정 잔차 척도 σ_R 의 결측 없음 대비 비율.
- **M4:** 실현 오경보율 — 칸 수준(검증 칸 97.5 % 임계)과 그룹 수준(행 4개 최댓값). 그룹 수준은 (a) 칸 임계를 그대로 적용, (b) **검증 그룹 점수의 97.5 백분위로 보정**한 임계, 둘 다.
- **M5 (A1 확인):** 하위 연구. 마스크와 λ 를 고정(λ ∈ {0.1, 1, 10})하고 잡음만 500번 다시 뽑아, 빈 칸에서 PS 예측값의 경험 분산과 새로 유도한 식 σ²·G(FᵀCF + λP)⁻¹FᵀCF(FᵀCF + λP)⁻¹Gᵀ 를 비교한다. 데이터로 고른 λ̂ 를 쓸 때의 비(경험 분산 / 식)도 보고한다.

## 4. 설계 (기본 조건 + 한 요인씩 + 두 요인 격자)
- **기본:** N = 10, L1, G, MCAR r = 0, p = 0, 이상 혼합 Δ = 2.
- **한 요인씩:** F1 창 수 N · F2 평활도 L · F3 결측(MCAR 0.3/0.5/0.7, BURST, MNAR) · F4 이상(유형 3 × 크기 3) · F5 오염 p · F6 잡음.
- **두 요인 격자:** G1 N × MCAR r (4 × 4) — PS 가 보간보다 나은 곳 찾기 · G2 L × MCAR r (3 × 4) · G3 잡음 × 오염 (3 × 3).
- **반복:** 설계 칸마다 R = 100 (반복마다 새 단위·노드 12). 반복 seed = 10000 + 칸 번호 × 1000 + 반복. 실행 시간이 6시간을 넘을 것으로 보이면 **실행 전에** R = 50 으로 줄이고 그 사실을 이 문서에 덧붙인다.

## 5. 판정 규칙
- 짝 차이(같은 반복에서 두 참조의 M1 차이)의 평균과 몬테카를로 표준오차(SE)를 낸다.
- 허용오차 tol = max(0.01, 2 SE). 평균 차이 > tol 이면 이김, |차이| ≤ tol 이면 대등, < −tol 이면 짐.
- 선택 단계가 없으므로 검증·테스트 판정 구분 없이 한 번 실행한다.

## 6. 미리 정한 예상 (실행 전)
| ID | 조건 | 예상 | 근거 |
|---|---|---|---|
| S1 | 기본, 결측 없음 | PS ≈ CG ≈ CF ≈ CI (대등). L1·L2 에서 NM 은 짐 | 명제 1, 원고 4.1절 |
| S2 | MCAR r ≥ 0.5, N ≤ 5 | CG 는 크게 짐. CF·CI 는 격차 대부분을 메움. PS − CI 는 양(+)이고 N 이 작고 r 이 클수록 커진다(G1) | 명제 3·4: 칸 평균 잡음 σ²/c 대 행 단위 σ²·ED/n |
| S3 | L2, N = 3, r = 0 | PS − CI < 0 가능(평활 바이어스) | 명제 4 바이어스 항, 원고 4.4절 f = 0.1 |
| S4 | L0 평탄 | NM ≥ PS(d = 2), PS1 ≈ NM | 명제 1(2)·(3), D6 탐색 결과 |
| S5 | T3·CN 잡음 | 제곱 손실 참조(CG·CF·CI·NM·PS·PS1)가 짐. CMI·NMed·PSH·PS1H 가 낫다. L1 에서 PSH ≥ CMI, L0 에서 PS1H ≈ NMed | 견고 추정과 평활의 분리(A4) |
| S6 | 오염 p > 0 | 제곱 손실 참조가 같이 나빠진다. Huber 계열은 덜 나빠진다 | 원고 4.4절 |
| S7 | MNAR | 모든 참조가 낮은 값 칸에서 위로 편향, σ_R 증가. PS 와 CF·CI 는 대등 | 값 의존 결측은 어떤 채움으로도 고쳐지지 않음 |
| S8 | M5 | λ 고정이면 경험 분산 = 식(몬테카를로 오차 안). λ̂ 이면 비 1–1.3 | 선형 평활기 |
| S9 | M4, G 잡음 | 칸 수준 오경보율 ≈ 2.5 %(검증·테스트 같은 분포). 칸 임계를 그룹 최댓값에 쓰면 약 S 배까지 늘고, 그룹 점수로 보정하면 2.5 % 로 돌아온다 | 실데이터의 '테스트 > 검증'은 분포 이동 때문이라는 해석의 대조 |

- 판정 항목: S1–S7(M1 기준), S8(M5). S9 는 서술.
- 시뮬레이션은 실데이터 결과를 대신하지 않는다. 원고에는 "어떤 조건에서 어느 참조가 나은가" 지도로 쓴다.

## 실행 전 수정 (2026-10-28, 코드 작성 중 — 원문 위쪽은 고치지 않음)
등록 문서가 정하지 않은 구현 세부를 실행 전에 적는다. 예상과 판정 규칙은 바꾸지 않는다.
1. 이상 라벨: 더한 크기가 Δ/2 이상인 칸. spike·shift 는 이상 칸 전부, drift 는 뒤쪽 절반이 양성이다.
2. 보정은 원고와 같이 이상을 넣지 않은 깨끗한 검증 창으로 한다. 선택 단계가 없으므로 검증 창에는 이상을 넣지 않는다. 그룹 임계 (c) 도 깨끗한 검증 그룹 점수의 97.5 백분위다.
3. BURST 는 평균 손실 π = 0.5(설계 칸의 r 값으로 저장)·평균 길이 4. MNAR 은 r 을 쓰지 않는다.
4. 학습 오염은 테스트와 같은 이상 생성기(같은 유형·크기)로 학습 창의 비율 p 에 넣는다.
5. M5: 행 하나(S = 1), L1 모양, N = 5, MCAR r = 0.5. 빈 칸이 하나 이상이고 관측 시점이 2개 이상인 마스크 20개, 마스크마다 잡음 500회. λ 고정 {0.1, 1, 10} 과 SAP λ̂. 릿지는 구현과 같은 값을 식에 넣는다.
6. 설계 칸 수 43개(겹치는 칸은 한 번만 실행하고 태그를 모두 붙임), 반복 100.
7. 병렬 실행 시 BLAS 스레드 1(결과에 영향 없음). 실행 전 '빠른 점검'(설계 칸 3개 × 반복 2)은 오류와 실행 시간만 보고 지표는 보지 않는다.
8. 코드: `experiments/expR1_5_sim.py`.
