## 1. 군집을 반영한 불확실성 (A5, B3)
- 현재(`analysis/63_math_paired_stats.py`): 짝 차이를 i.i.d. 재표집한 부트스트랩(B = 5000)과 Wilcoxon 양측 검정. 군집 처리 없음.
- 바꾸는 것: 원고 표 3–10 의 모든 대비에 대해
  - **2단계 군집 부트스트랩:** 군집(D1 방 3 · D2 환경 4 · D6 scan 12)을 복원 추출하고, 뽑힌 군집 안에서 짝을 복원 추출한다. B = 5000, seed = 대비 이름의 crc32(현행과 같음).
  - **단위별 평균 차이**와 양(+) 비율을 표로 보인다(보충 자료).
  - Wilcoxon p 값은 원고에서 뺀다(독립 가정 위반).
  - '동등' 표현 기준: 군집 구간 전체가 ±허용오차 안이면 "허용오차 여유 안에서 동등", 아니면 "허용오차 안(평균)"으로 쓴다.
- 입력은 기존 1차 출력 csv(재실행 없음). 출력 `results/expR1/inference/`. 코드 `analysis/76_cluster_bootstrap.py`.
- 짝 통계 표 머리말의 "seed 0" 표기는 사실과 달라(실제 seed 는 대비 이름의 crc32) 함께 고친다.

## 2. 임계값 보정과 오경보율 (A 추가 4, C7)
- 점수 배열이 저장돼 있지 않으므로(5-2절) PS 와 CG 를 깨끗한 D1·D2·D6 에서 다시 적합·채점한다(선택 단계 없음, 원고와 같은 설정).
- 비교하는 보정 방식:
  - (a) 현행: 검증 칸 점수의 97.5 백분위 하나를 칸과 그룹(앵커 최댓값)에 그대로 적용.
  - (b) 행별 임계: 행마다 검증 칸 97.5 백분위.
  - (c) **그룹 임계: 검증 그룹 점수(앵커 최댓값)의 97.5 백분위.**
- 보고: 검증·테스트의 칸 수준·그룹 수준 실현 오경보율(정상 칸·정상 그룹 기준), 같은 임계에서의 재현율·F1. 서술만(판정 없음).
- 미리 정한 예상: (c) 는 그룹 수준 오경보율을 검증에서 2.5 % 로 맞추고, 테스트에서는 분포 이동만큼 높다(D1 약 1.2–1.9배, 기존 `results/exp6/part2/table_F_test.csv` 와 같은 양상).
- 출력 `results/expR1/thresholds/`, 코드 `experiments/expR1_3_thresholds.py`.

## 3. 딥 모델 학습 seed 변동 (A5)
- 대상: TranAD, GDN, 2-D Conv-AE (R1-4 1부의 딥 탐지기). 깨끗한 D1·D2, 원고 표 4 의 선택 설정, model seed ∈ {0, 1, 2, 3, 4}.
- 보고: 학습 seed 사이 SD 와 주입 seed 사이 SD 를 나란히 보이고, PS − 모델 차이가 학습 seed 에 따라 판정(이김/대등/짐)이 바뀌는지 적는다. 서술만.
- 테스트 분할을 쓰지만 판정을 바꾸지 않는 변동 보고다. seed 0 결과는 이미 본 값이다.
- 출력 `results/expR1/train_seeds/`, 코드 `experiments/expR1_3_train_seeds.py`.

## 4. 빈 칸 예측 분산의 실데이터 계산 (A1, 서술)

- 학습 데이터만 쓰며 탐지 성능을 보지 않는다. 출력 `results/expR1/pred_var/`, 코드 `analysis/77_pred_variance.py`.
