## 1. 공정성 규칙
1. **입력 변형:** 범용 모델(선형·고전·딥러닝)은 두 입력 중 하나를 검증으로 고른다.
   - raw: F01 합성 후 값 (S1 z-score)
   - nc: 노드별 셀 평균(M01 기준)을 뺀 잔차. 제안 모델과 같은 위치 정보를 준다.
2. **D2 마스크:**
   - 학습: NLOS(마스크 0) 셀을 정상 기준값으로 채운다. raw는 행 평균(0), nc는 잔차 0으로 채운다.
   - **테스트:** 마스크를 쓰지 않고 실제 값을 넣는다. 마스크는 기하 NLOS 라벨이라, 테스트 입력에 쓰면 라벨 누수다.
   - 제안 모델은 행마다 독립이라 테스트에서 NLOS 셀이 다른 셀 점수에 영향을 주지 않는다. 센서 간 모델에서 NLOS 셀이 다른 셀을 오염시키는 것은 그 방법의 특성으로 둔다.
3. **점수:** 셀마다 |재구성(또는 예측) 오차|를 행별 검증 SD로 나눈다. Isolation Forest는 시점 단위 점수를 그 시점의 모든 셀에 같게 준다 (위치화 지표는 의미 없음, 보고만).
4. **탐색 예산:** 모델마다 검증 구성 최대 8개 (입력 변형 포함). 데이터(D1, D2)마다 검증 AUC-PR 평균이 가장 높은 구성을 고른다. 제안 모델 PS는 튜닝이 없다.

## 2. 모델별 구성 (검증 탐색 격자)

# 실험 1 비교 모델 2차 (사전 등록, 2026-10-11)

## 0. 범위
- 1차에서 미룬 모델이다: Laplacian-RPCA, RRR, Transformer, 2D Conv-AE, PCA SPE 기여도(RBC), GDN, OmniAnomaly, InterFusion.
- 평가·공정성 규칙·탐색 예산·판정은 1차와 같다 (위 1절, 3절):
  - 입력 raw/nc를 검증으로 고른다. 모델마다 검증 구성은 최대 8개다.
  - D2 마스크는 학습에만 쓴다.
  - 셀 점수 = |오차| / 행별 검증 SD, 임계 = 검증 97.5 백분위.
  - PS − 모델 짝지은 AUC-PR, 허용오차 D1 0.0165 · D2 0.0171.
  - 딥러닝은 시드 0, Adam 1e-3, 200 epoch.
- 출력: `results/exp1_baselines/batch2/`. 1차 결과 파일은 건드리지 않는다.

## 1. 공개 코드 모델의 처리 (실행 전 결정)
- 원 공개 코드는 이 환경에서 그대로 돌릴 수 없다.
  - InterFusion·OmniAnomaly는 TensorFlow 1.x와 Python 3.6–3.7이 필요하다. 이 환경은 Python 3.10, PyTorch 2.10이고 TensorFlow가 없다.
  - GDN은 구 버전 torch_geometric에 의존한다.
- **GDN·OmniAnomaly는 논문의 핵심 구조를 PyTorch로 재구현한다.** 표와 본문에는 "재구현"으로 적는다. 원 코드의 수치와 직접 비교하지 않는다.
- **InterFusion은 이번 차수에서 뺀다.** 2단계 계층 VAE, 사전 필터, MCMC 대치까지 재구현 규모가 커서다.
  - 다시 열 조건: TF1 환경을 따로 만들 수 있거나, 심사에서 요구될 때. 그때 이 문서 규칙 그대로 돌린다.
- **RBC는 따로 돌리지 않는다.** 이 저장소의 셀 점수 규칙에서는 PCA 잔차와 같은 점수가 되기 때문이다.
  - RBC_i = (ξ_iᵀ C̃ x)² / C̃_ii (C̃ = I − PPᵀ)이고, PCA 셀 잔차는 R_i = (C̃ x)_i다. 따라서 √RBC_i = |R_i| / √C̃_ii다.
  - √C̃_ii는 행마다 상수다. 행별 검증 SD로 나누면 두 점수가 같아진다.
  - 결과는 1차 PCA-SPE 행으로 갈음한다.

## 2. 모델별 구성 (검증 탐색 격자)
| 모델 | 정의 | 격자 |
|---|---|---|
| Laplacian-RPCA | X = L + S, min ‖L‖_* + λ‖S‖₁ + γ tr(L Φ Lᵀ) (ADMM). Φ = 센서 간 \|상관\| 그래프의 정규화 Laplacian (학습 입력). 학습 L의 SVD 부분공간(에너지 0.9, 1차 RPCA 선택값)에 투영 | λ = c/√max(n, S), c ∈ {0.5, 1} × γ ∈ {0.1, 1} × 입력 {raw, nc} |
| RRR | 감소 랭크 시차 회귀 y_t = c + B y_{t−1}, rank(B) ≤ r (윈도우 안, 표준 RRR: OLS 적합값의 상위 r 특이벡터로 사영). t = 0은 학습 평균으로 예측 | r ∈ {1, 2, 4, 8} (센서 수 이하만) × 입력 {raw, nc} |
| Transformer | 시점 마스킹 재구성. 시점 임베딩 + 학습 위치 임베딩 + Transformer encoder 2층(4 heads). 학습: 시점 25 %를 마스크 토큰으로 바꾸고 그 시점만 복원. 점수: 각 시점을 하나씩 가리고 복원한 오차. 마스킹이 없는 Transformer AE는 항등 사상을 배우기 쉬워 쓰지 않는다 | d_model ∈ {16, 32} × 입력 {raw, nc} |
| 2D Conv-AE | 윈도우(센서 × 시간)를 1채널 영상으로 본 합성곱 오토인코더 (stride 2 축소 후 복원) | 채널 ∈ {8, 16} × 입력 {raw, nc} |
| GDN (재구현) | Deng & Hooi (2021). 센서 임베딩, 코사인 top-k 그래프, 그래프 어텐션으로 다음 시점 예측. 윈도우 w = 5, k = min(S − 1, 5). 윈도우 앞 w 스텝은 첫 값을 반복해 채운다. 점수는 공통 규칙 (예측 오차 / 행별 검증 SD) | 임베딩 ∈ {16, 32} × 입력 {raw, nc} |
| OmniAnomaly (재구현) | Su et al. (2019). GRU 추론망 + 평면 흐름(K = 20) + 선형 가우스 상태공간 사전분포 + GRU 생성망, ELBO 학습. 점수 = 셀별 표준화 재구성 오차 \|x − μ_x\| / σ_x (재구성 확률의 이차항). GRU 은닉 64 | 잠재 차원 ∈ {3, 8} × 입력 {raw, nc} |

# 비교 모델 2차 수정 (사전 등록, 2026-10-12, 문헌 대조 후·2차 테스트 전)

근거: `doc/문헌대조_결과.md` 1절 #1, #5, #7, #8. 2차 검증 탐색이 도는 중에 문헌 대조로 발견했다. 아래 모델의 검증 결과 일부는 이미 봤다 (GDN·LapRPCA의 D1 검증, 1차 USAD의 검증·테스트).

| 모델 | 문제 | 수정 | 기존 결과 처리 |
|---|---|---|---|
| **USAD** (1차) | 두 손실을 합쳐 역전파해 적대 항이 상쇄됨 | 원 논문 Alg. 1·공개 코드처럼 옵티마이저 2개(E+D1 ← L_AE1, E+D2 ← L_AE2)를 배치마다 번갈아 갱신. 이름 **USADFIX**. 격자는 1차와 같음 (잠재 {8, 16} × 입력 {raw, nc}) | 1차 USAD 행은 "학습 오류판"으로 남기고 주장에서 뺀다 |
| **GDN** (2차) | t = 0 이력이 목표의 복사본 (누수) | 윈도우 앞 이력을 0으로 채움 (nc 입력에서 0 = 기준값, raw에서 0 = 행 평균) | 2차 탐색의 GDN 행은 "누수판(GDN_v0)"으로 남김 |
| **LapRPCA** (2차) | γ 효과가 입력 척도에 따라 달라짐. \|ρ\| 가중은 음의 상관 센서를 같게 당김 | 학습 평균·SD로 열 표준화한 뒤 적합. 가중 = max(ρ, 0). 이름은 그대로 두고 "센서 그래프 변형 (Shahid 2015는 표본 그래프)"으로 표기 | 2차 탐색 행은 "LAPRPCA_v0"으로 남김 |
| **RBC^φ** (추가) | RBC 동치 주장은 SPE에서만 성립 | Alcala & Qin (2009) 결합 지표 Φ = C̃/δ² + D/τ²의 RBC: √RBC_i = \|(Φx)_i\| / √Φ_ii. 학습으로 열 표준화. δ²는 Jackson–Mudholkar(Box 근사) SPE 한계, τ² = χ²_k. α = 0.99. PCA의 데이터별 선택 구성(입력, 설명 분산)을 그대로 쓴다. 이름 **RBCPHI**, 구성 1개 | — |

- 탐색·선택·판정 규칙은 2차와 같다. 출력: `results/exp1_baselines/batch2_fix/`.
- 2차 테스트는 다음 구성으로 한 번 돌린다.
  - 2차 선택 구성: RRR, Transformer, 2D Conv-AE, OmniAnomaly
  - 수정 선택 구성: USADFIX, GDN, LapRPCA, RBCPHI
- 실험 9(D4)에서도 USAD 대신 USADFIX를 쓰고, GDN은 수정판을 쓴다.
- **추가 수정 (2026-10-12, USADFIX 검증 결과를 본 뒤):**
  - USADFIX의 검증 AUC-PR이 D1 0.44, D2 0.18로 크게 낮았다.
  - 원 논문은 입력을 [0, 1]로 min-max 정규화하고 출력에 Sigmoid를 쓴다 (부록 A.4). 그래서 AE2의 최대화 단계가 유한한 범위에 묶인다.
  - 이 저장소는 z-score 입력이라 Sigmoid를 뺐다. 그러면 적대 단계가 끝없이 커져 학습이 무너진 것으로 보인다 (추정).
  - 그래서 그 부분까지 원형대로 맞춘 **USADFIX2**를 추가한다. 학습 몫의 행별 최소·최대로 [0, 1] 정규화하고, 복호기 출력에 Sigmoid를 쓴다. 격자는 같다.
  - 행별 아핀 정규화라 공통 점수 규칙(행별 검증 SD로 나눔)에서 척도는 지워진다.

## 1. 모델 정의 (실행 전 고정)
| 모델 | 정의 | 격자 |
|---|---|---|
| TranAD (재구현) | 입력 (S×T) 윈도우를 시점 토큰열로 보고 [x_t ; focus_t]를 선형 임베딩 + 학습 위치 임베딩 → Transformer encoder 1층(4 heads) → 복호기 2개(TransformerDecoder 1층, 학습 질의) → 시점별 S차원 복원. **2단계:** 1단계 focus = 0으로 O1·O2, 2단계 focus = (O1 − x)²로 Ô2. **손실(논문 Alg. 1):** L1 = w‖O1 − x‖² + (1 − w)‖Ô2 − x‖² (encoder + 복호기 1), L2 = w‖O2 − x‖² − (1 − w)‖Ô2 − x‖² (복호기 2), w = 1/n (n = epoch, 공개 코드와 같음), 옵티마이저 2개, 기울기 클리핑 1.0. **점수:** 셀별 ½(O1 − x)² + ½(Ô2 − x)² 의 제곱근(= 오차 크기; 공통 규칙으로 행별 검증 SD로 나눔) | d_model ∈ {16, 32} × 입력 {raw, nc} |
| Anomaly Transformer (재구현) | 시점 토큰 임베딩 + 위치 임베딩 → Anomaly-Attention 2층(4 heads): series association S = softmax(QKᵀ/√d), prior association P = 정규화 가우스 커널 exp(−(i−j)²/2σ_i²) (σ_i는 시점별 학습, 헤드별) → 선형 복원. **Association discrepancy** = 층·헤드 평균 [KL(P‖S) + KL(S‖P)] (시점별). **Minimax(논문 식 5·6, k = 3):** 최소화 단계 loss₁ = ‖x̂ − x‖² − k·‖AssDis(P, S.detach)‖₁, 최대화 단계 loss₂ = ‖x̂ − x‖² + k·‖AssDis(P.detach, S)‖₁, 배치마다 두 번 역전파. **점수(논문 식 7):** 시점 가중 softmax_t(−AssDis_t) × 셀별 (x̂_st − x_st)² 의 제곱근 | d_model ∈ {16, 32} × 입력 {raw, nc} |

- 두 모델 모두 공개 코드의 긴 슬라이딩 윈도우(예: 100)가 아니라 이 저장소의 T = 12 윈도우를 그대로 쓴다. 이는 비교군 전체(LSTM-AE·Transformer 등)와 같은 조건이다.
- **발산 대비(실행 전 결정):** 적대 항 때문에 손실이 비유한이 되거나 검증 AUC-PR이 우연 수준(≤ 양성 비율 + 0.05)이면, (a) 그 사실을 기록하고 (b) 적대 항을 뺀 단일 손실형(공개 코드 형태에 가까움)을 같은 격자로 한 번 더 돌려 **둘 다 보고**한다. 판정은 원형(적대 항 포함)으로 하되, 발산했으면 단일 손실형으로 한다.

# 비교 모델 3차 정정: Anomaly Transformer minimax 방향 (사전 등록, 2026-10-14, 원문 대조 후 · 정정판 실행 전)

## 0. 발견
- 2026-10-14 저자가 원문 PDF(`doc/papers/paper_05/Anomaly Transformer_Time series anomaly detection with association discrepancy.pdf`, ICLR 2022)를 올려 세션이 전문 대조했다.
- 논문 식 (4)–(5): L_Total(X̂, P, S, λ) = ‖X − X̂‖² − λ‖AssDis(P, S)‖₁. **최소화 단계** L_Total(X̂, P, S_detach, −λ) — prior P 가 series S(고정)에 가까워지도록 차이를 줄인다. **최대화 단계** L_Total(X̂, P_detach, S, λ) — series S 가 prior(고정)와의 차이를 키운다. 논문은 "차이를 직접 키우면 가우스 커널의 σ 가 극단적으로 작아져 prior 가 의미를 잃는다"고 적는다.
- 3차 등록 정의(위 1절)와 구현(`src/baselines/models.py` `AnomalyTransformer.fit`)은 **detach 대상이 반대**다: loss₁ = rec − k‖AssDis(P, S.detach)‖ (prior 가 차이를 키움), loss₂ = rec + k‖AssDis(P.detach, S)‖ (series 가 차이를 줄임). 등록 문서가 "논문 식 5·6"이라 적었지만 방향이 틀렸다. 따라서 3차의 Anomaly Transformer 결과(D1 +0.027, D2 +0.592)는 원형 알고리즘의 결과가 아니다.
- 같은 대조에서 일치를 확인한 것(바꾸지 않음): prior = 학습 σ 가우스 커널을 행 합으로 정규화(Rescale), series = Softmax(QKᵀ/√d), AssDis = 층 평균 대칭 KL (Algorithm 2 는 헤드 평균 후 KL — 우리는 헤드별 KL 후 평균; 등록 그대로 둠), 점수 = Softmax(−AssDis) ⊙ ‖X_i − X̂_i‖² (식 6; 등록 문서의 '식 7' 은 오기), 손실 가중 λ = 3. 원형 크기(3층, d_model 512, 8 heads, 윈도우 100)와의 차이(2층, 4 heads, d_model {16, 32}, T = 12)는 등록된 축소로 그대로 둔다.

## 1. 정정판 ANOMTRANSFIX (실행 전 고정)
