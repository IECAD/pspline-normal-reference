# 정리 1 — 참조 오차는 행 중심화된 점수의 탐지 지표에 2차로, V_e 하나를 통해 들어온다

순서의 정직한 기록: 이 정리는 실험 뒤에, 4.8절의 창 수 의존과 보간과의 작은 일관된 차이를 설명하려고 세웠다. 편지에 그렇게 쓴다.

## 1. 설정 (원고 3.4절·명제 4′ 그대로)

행 하나를 고정하고 행 첨자를 뺀다. 참 정상 곡선 $m\in\mathbb R^T$, 적합된 참조 $\hat m$ (학습 데이터에 조건부로 고정), 오차 $e=\hat m-m$,
$$\bar e=\tfrac1T\sum_t e_t,\qquad d_t=e_t-\bar e,\qquad \sum_t d_t=0,\qquad V_e=\tfrac1T\sum_t d_t^{2}.$$
검증 창(정상, 전부 관측)에서 잔차 $R_{jt}=\varepsilon_{jt}-e_t$ 의 행 통계는 $J\to\infty$ 에서 $\mu=-\bar e$, $\sigma_R^{2}=\sigma^{2}+V_e$ (명제 4′).
시험 칸 $y_t=m_t+\Delta_t+\varepsilon_t$, $\Delta_t=\Delta\,\mathbf 1[t\in\mathcal A]$. 점수(3.4절)
$$A_t=\frac{|y_t-\hat m_t-\mu|}{\sigma_R}=\frac{|\varepsilon_t+\Delta_t-d_t|}{\sigma_R}.$$

**가정.**
- (N) $\varepsilon_t$ 는 i.i.d., 분포함수 $F_\varepsilon$, 밀도 $f$ 는 $C^{2}$ 이고 $f, f', f''$ 유계.
- (H3) 이상 집합 $\mathcal A$ 는 $e$ 와 독립이고, 각 시점이 이상일 확률이 같다: $\Pr(t\in\mathcal A)=\pi$ 가 $t$ 에 무관.
- (Φ) 탐지 지표 $\Phi(F_0,F_1)$ 는 정상 칸 점수의 분포함수 $F_0$ 와 이상 칸 점수의 분포함수 $F_1$ 의 범함수로, 순위에만 의존하고(두 분포에 같은 단조 변환을 가해도 불변), $(F_0^{(0)},F_1^{(0)})$ 에서 sup-노름에 대해 Fréchet 미분 가능. AUROC 는 $\Phi=\int F_0\,dF_1$ 로 정확히 쌍선형이다. AUC-PR 은 양성률 $\pi$ 가 주어지면 $(F_0,F_1)$ 의 매끄러운 범함수이다(밀도가 양인 구간에서).

## 2. 진술

**정리 1.** (N), (H3), (Φ) 아래, $\max_t|d_t|\to0$ 일 때
$$\Phi(e)=\Phi(0)+\kappa\,V_e+o(V_e),\qquad \kappa=\tfrac12\,D\Phi\big[\partial_d^{2}G_0(\cdot;0),\ \partial_d^{2}G_1(\cdot;0)\big],$$
여기서 $G_0(s;d)=\Pr(|\varepsilon-d|\le s)$, $G_1(s;d)=\Pr(|\Delta+\varepsilon-d|\le s)$ 이고 $D\Phi$ 는 $\Phi$ 의 Fréchet 미분이다. $\kappa$ 는 $f$, $\Delta$, $\pi$ 에만 의존하고 참조에는 의존하지 않는다. 특히 이 차수에서 $\Phi$ 는 오차 벡터 $e$ 에 $V_e$ 를 통해서만 의존하며, 오차가 행의 어느 칸에 있는지에는 의존하지 않는다.

**보충 (1차 항).** 일반적으로 1차 항은 $\big(\sum_t (w_t-T^{-1})\,d_t\big)\,D\Phi[\cdot,\partial_dG_1]+\big(\sum_t (u_t-T^{-1})\,d_t\big)\,D\Phi[\partial_dG_0,\cdot]$ 이다. $w_t$ 는 이상 칸이 시점 $t$ 에 있을 확률, $u_t$ 는 정상 칸의 그것. (H3) 이면 $w_t=u_t=T^{-1}$ 이고 $\sum_t d_t=0$ 이므로 사라진다. 행 중심화를 하지 않으면($\mu=0$) $d_t$ 자리에 $e_t$ 가 들어가 $\sum_t e_t=T\bar e$ 가 남고, 1차 항 $\bar e\,D\Phi[\partial_dG_0,\partial_dG_1]$ 이 생긴다. $f$ 가 대칭이면 $\partial_dG_0(s;0)=f(s)-f(-s)=0$ 이지만 $\partial_dG_1(s;0)=f(s-\Delta)-f(-s-\Delta)\ne0$ 이므로, 공통 오프셋은 이상 칸 점수를 1차로 움직인다. 중심화가 이것을 없앤다.

## 3. 증명

**(i) 척도.** $\Phi$ 는 순위에만 의존하므로 공통 인자 $1/\sigma_R$ 은 $\Phi$ 를 바꾸지 않는다. 이후 점수를 $S_t=|\varepsilon_t+\Delta_t-d_t|$ 로 둔다.

**(ii) 혼합 표현.** (H3) 에서 정상 칸의 시점은 $\{1,\dots,T\}$ 위에 균등하고 $d$ 와 독립이므로
$$F_0(s)=\tfrac1T\sum_t G_0(s;d_t),\qquad F_1(s)=\tfrac1T\sum_t G_1(s;d_t),$$
$G_0(s;d)=F_\varepsilon(s+d)-F_\varepsilon(-s+d)$, $G_1(s;d)=F_\varepsilon(s-\Delta+d)-F_\varepsilon(-s-\Delta+d)$ ($\Delta$ 의 부호가 섞이면 부호별 평균; 아래 논증은 그대로).

**(iii) 전개.** (N) 에서 $G_k(\cdot;d)$ 는 $d$ 에 대해 $C^{2}$ 이고 $s$ 에 균등하게
$$G_k(s;d)=G_k(s;0)+d\,\partial_dG_k(s;0)+\tfrac{d^{2}}{2}\,\partial_d^{2}G_k(s;0)+R_k(s;d),\qquad \sup_s|R_k(s;d)|\le C|d|^{3},$$
$C=\sup|f''|/3$. $t$ 에 대해 평균하면 1차 항의 계수가 $T^{-1}\sum_t d_t=0$ 이므로
$$F_k-G_k(\cdot;0)=\tfrac{V_e}{2}\,\partial_d^{2}G_k(\cdot;0)+\rho_k,\qquad \sup_s|\rho_k(s)|\le C\,\tfrac1T\sum_t|d_t|^{3}\le C\max_t|d_t|\;V_e .$$

**(iv) 범함수.** (Φ) 의 Fréchet 미분 가능성으로 $\Phi(F_0,F_1)-\Phi(F_0^{(0)},F_1^{(0)})=D\Phi[F_0-F_0^{(0)},\,F_1-F_1^{(0)}]+o(\|F_0-F_0^{(0)}\|_\infty+\|F_1-F_1^{(0)}\|_\infty)$. (iii) 를 넣으면 주항이 $\tfrac{V_e}{2}D\Phi[\partial_d^{2}G_0,\partial_d^{2}G_1]=\kappa V_e$ 이고 나머지는 $o(V_e)$ 이다. $\kappa$ 는 $G_0,G_1$ 의 $d=0$ 에서의 2차 도함수와 $\Phi$ 의 미분으로만 결정되므로 $f$, $\Delta$, $\pi$ 의 함수이고 참조에 무관하다. $\square$

**AUROC 의 닫힌 꼴.** $\Phi=\int F_0\,dF_1$ 이면 $D\Phi[h_0,h_1]=\int h_0\,dF_1^{(0)}+\int F_0^{(0)}\,dh_1$ 이고, $\partial_d^{2}G_0(s;0)=f'(s)-f'(-s)$, $\partial_d^{2}G_1(s;0)=f'(s-\Delta)-f'(-s-\Delta)$. 가우스 $f$ 에서는 $f'(s)=-sf(s)$ 로 수치 적분 한 줄이다. (AUC-PR 의 $\kappa$ 는 같은 식에 $\pi$ 가 들어간 $D\Phi$ 를 쓴다; 시뮬레이션에서는 적합으로 얻는다.)

## 4. 따름정리 1 — 칸 단위 결측에서의 동치류와 그것을 깨는 세 길

명제 4′ 의 마지막 식 $\mathbb E V_e=T^{-1}\sum_t\{\mathrm{Var}(e_t)+b_t^{2}\}-\{\mathrm{Var}(\bar e)+\bar b^{2}\}$ 를 참조마다 쓰면, 관측 패턴이 오차와 독립(H1)이고 칸이 반복 $c$ 회 중 손실률 $r$ 로 독립 손실될 때(명제 3)
$$\mathbb E V_e\;\approx\;\frac{\sigma^{2}}{c}\,a_{\mathrm{ref}}\;+\;r^{c}\,b_{\mathrm{ref}}\;+\;\beta_{\mathrm{ref}}^{2},$$
- $a_{\mathrm{ref}}$: 관측 칸의 분산 상수. 셀 평균 $1-T^{-1}$(명제 4′); P-스플라인 $\le \mathrm{ED}/T$ 꼴(명제 4(2)); 보간·행 평균 채움은 셀 평균과 같다.
- $b_{\mathrm{ref}}$: **빈 칸 하나의 평균 제곱 오차.** 단위 채움 $g^{2}$ ($g$ = 노드–단위 수준 차, D1 에서 $g^{2}/\sigma^{2}$ 는 수십–수백: $\sigma_R$ 비율 3.4–12.5 에 $r^{c}\approx0.15$); 행 평균 채움 $\mathrm{Var}_t(m)$(창 안 패턴의 분산); 선형 보간 $O(\Delta^{4}\|m''\|^{2})$ + 이웃 분산; P-스플라인은 명제 4(1) 의 빈 칸 예측 분산(D1 마스크 중앙값 0.07–0.12$\sigma^{2}$).
- $\beta_{\mathrm{ref}}$: 평활 편향(P-스플라인; 창이 적고 정밀할 때 커짐, 4.4절).

정리 1 과 합치면: **두 참조의 탐지 차이는 $\kappa\,\Delta\mathbb E V_e$ 이다.** 그러므로
1. **동치류.** $b_{\mathrm{ref}}=O(\sigma^{2})$ 인 참조들(행 평균 채움, 보간, P-스플라인, 관측 칸의 셀 평균)은 $\mathbb E V_e=O(\sigma^{2}/c)$ 로 같은 차수이고 탐지 차이는 $O(1/c)$ 이다. 차수가 같을 뿐 상수는 다르며($a$, $b$), 그 상수 차가 D1 의 +0.001~+0.023 과 시뮬레이션 창 수 축(+0.048/+0.033/+0.017/+0.008 at $c$ = 3/5/10/20)이다.
2. **깨는 길 (i) 단위 채움.** $b=g^{2}\gg\sigma^{2}$ 이면 $r^{c}g^{2}$ 가 $\sigma^{2}$ 의 수십 배가 되어 전개 영역을 벗어난다(붕괴, 0.52–0.77). $c$ 가 커지면 $r^{c}$ 로 사라진다(D2, $c=19$: 동률).
3. **깨는 길 (ii) H2 실패(끝 외삽).** 빈 칸이 관측 범위 밖이면 P-스플라인의 $b$ 는 명제 4(1) 로 간격의 제곱으로 자라고(극단 221$\sigma^{2}$), 상수 끝 채움 보간의 $b$ 는 기울기 × 간격의 제곱이다.
4. **깨는 길 (iii) H1 실패(값 의존 손실).** 셀 평균이 편향되어 모든 참조의 $\mathbb E V_e$ 에 $c$ 로 줄지 않는 항이 생긴다. 어느 참조가 더 커지는지는 정리가 정하지 않고 두 선형 사상의 계산이 정한다. 시뮬레이션 MNAR 칸: CI 0.204 대 PS 0.103, 탐지 차 +0.031 = $\kappa\Delta V_e$ 예측 +0.028.

**H3 실패.** 이상이 빈 칸(오차가 큰 칸)에 몰리면 1차 항 $\sum_t(w_t-T^{-1})d_t$ 가 살아나 같은 $V_e$ 로도 탐지가 다르다. NLOS 가 패킷 손실을 만들면 현실이 이 경우일 수 있다. 이 논문의 주입 실험은 (H3) 를 만족한다(이상 위치는 마스크와 독립).
