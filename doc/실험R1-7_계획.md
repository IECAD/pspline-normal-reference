# 실험 R1-7 계획: 새 무필터 UWB 데이터에서 Huber 변형과 견고 기준선 확인 — D8 HYMN (사전 등록, 2026-10-29)

작성: 2026-10-29 · 상위: `paper/mathematics/revision_r1/심사의견_정리.md` 4-2절(결정 D10 (가)), `doc/실험R1-4_계획.md` 2부(D6 견고 기준선), `data_ext/D8_hymn/STRUCTURE.md`(등록 전에 본 값) · 대응 의견: **A4·B4**(주), A5·B3(추론), C5(공개 데이터 근거) · 대상: 이 저장소에서 작업하는 사람과 AI 어시스턴트

## 0. 목적
- 심사자 A·B 는 Huber 변형(PSH, PS1H)의 주장을 D6 하나의 이상값 제외 평가에 기대지 말고, **필터하지 않은 새 데이터**에서 확인하라고 했다.
- R1-4 2부(D6)에서 확인한 것: 전체 평가에서 PSH − PS +0.029 이김, 그러나 단순 견고 참조(CMI, NMed)가 Huber 변형과 같다 → 개선은 견고 추정에서 온다.
- 이 실험은 같은 비교를 **다른 장비·건물·잡음 수준의 공개 UWB 데이터(HYMN)** 에서 한 번 더 한다. 보조로, 학습 칸에 결측을 더한 조건에서 원고의 주 주장(빈 칸이 많을 때 PS 참조)을 공개 UWB 데이터로 다시 본다.

## 1. 데이터와 틀 (D8)
- 출처·라이선스·지문·등록 전에 본 값: `data_ext/D8_hymn/STRUCTURE.md`. 로더 `src/data/d8.py`(sqlite 를 읽기 전용으로 열고 JSON 만 해석; 내려받은 코드는 실행하지 않음).
- **노드 = 지점 48개 전부**(격자 42 + 전이 T01–T06). **행 = 앵커 10개 거리**(DIST_A1–A10). **창 = 주 태그 라운드 12회**(T = 12, 약 15 s). **단위 = 데이터 전체 하나**(표준화 S1 은 단위의 학습 칸).
- 분할(시간 순, 지점마다): 마지막 창 2개 테스트, 그 앞 2개 검증, 나머지 학습(6–8개).
- 연결 앵커: 노드마다 **자연(결측 추가 전) 학습 관측 ≥ 12** 인 앵커(D6 규칙). 점수·라벨은 연결 앵커이면서 관측된 칸만 쓴다. 적합은 노드의 관측 칸 전부를 쓴다.
- 합성 코드: V1 S1 O1 T4 (실험 10·R1-4 2부와 같음). 보정 = 검증(stats = val), 임계 백분위 97.5.

## 2. 이상 주입 (검증·테스트 창)
- D1 시나리오 SC1–SC3 그대로(`configs/exp3.yaml`): 주 크기와 ×3(보고). HYMN 링크 MAD 중앙 0.10 m 라 주 크기(0.3–1.6 m)를 주로 쓴다(D6 는 잡음 SD 1 m 라 ×3 도 봤음).
- 대상 앵커 = 연결 앵커 중 그 창에서 라운드 절반 이상 관측된 앵커(D6 규칙). 주입 칸이 관측되지 않은 칸이면 라벨 NaN.
- 주입 seed: 검증 142–146, 테스트 42–46.

## 3. 참조와 조건
- 참조(탐지기는 self, 선택 단계 없음): **CG**(셀 평균, 빈 칸 = 단위 행 평균) · **CI**(셀 평균 + 시간 선형 보간) · **CMI**(칸별 중앙값 + 보간) · **NM**(노드 평균) · **NMed**(노드 중앙값) · **PS**(K = T, d = 2, SAP) · **PS1**(d = 1) · **PSH**(d = 2, Huber) · **PS1H**(d = 1, Huber). 코드는 `experiments/expR1_4_robust.py` 의 정의(`SPEC`, `median_surface`)를 그대로 쓴다.
- 조건:
  - **N 자연(주):** 데이터 그대로(실제 결측 7 %, 이상값 필터 없음).
  - **M 결측 추가:** 학습 관측 칸마다 확률 r = 0.7 로 지운다. 조건 seed 0–2, rng = default_rng(2000 + 조건 seed)(R1-6 과 같은 규칙). 검증·테스트 창은 그대로. 연결 앵커·이상값 제외 칸·주입은 N 과 같게 둔다(같은 평가 칸에서 비교).

## 4. 평가
- **주 평가 = 전체(무필터) 평가.** 보조 = 이상값 제외 평가(탐색): 노드 × 앵커의 **자연 학습** 중앙값에서 1 m 넘게 벗어난 칸을 **주입 전 원값으로** 정해 평가에서만 뺀다(실험 10·R1-4 규칙). 뺀 양성·음성 칸 수를 세어 저장한다.
- 지표: 셀 AUC-PR(주, 단위 전체 칸을 모아 (시나리오, 주입 seed)마다 하나), HitRate, 운영 임계 셀 F1, 실현 셀 오경보율(라벨 0 칸에서 점수 > 임계 비율).
- 점수·라벨 배열을 저장해 군집 부트스트랩에 쓴다.

## 5. 허용오차·판정·추론
- 허용오차: tol = max(검증, 조건 N, 주 크기, 전체 평가에서 CG 의 주입 seed 간 SD, 0.01) (R1-6 과 같은 규칙: seed 마다 시나리오 평균을 낸 뒤 seed 간 SD). **검증 실행 직후, 테스트 전에** 이 문서에 적는다.
- 짝 = (시나리오, 주입 seed[, 조건 seed]). 평균 차이 > tol 이면 이김, < −tol 이면 짐, 나머지 대등(실험 6 과 같은 정의). 양(+) 비율을 함께 적는다.
- 판정은 검증에서 한다. 테스트는 판정을 바꾸지 않고 **한 번** 실행해 그대로 보고한다. 검증과 테스트가 다르면 둘 다 적는다.
- **군집 부트스트랩(보고):** 군집 = 지점(48). B = 2000 회, 지점을 복원 추출해 뽑힌 지점의 칸을 (중복 포함) 모아 짝마다 AUC-PR 차이를 다시 계산하고 짝 평균을 낸다. 백분위 95 % 구간. '동등' 표현은 구간 전체가 ±tol 안일 때만 쓴다.

## 7. 원고 반영 원칙
- H-H1–H-H4 가 예상대로면: "필터하지 않은 새 UWB 데이터(HYMN)에서도 Huber 변형이 PS 보다 낫고, 칸별·노드 중앙값이 그와 같다 — 개선은 견고 추정에서 온다"를 4.6절과 표 11 에 더하고, A4·B4 에 '새 데이터로 확인'으로 답한다.
- H-H1 이 대등이나 짐이면: 그대로 보고하고 Huber 변형의 개선을 'D6 에서만 확인된 것'으로 낮춘다(초록·결론 문구 조정).
- H-H3 에서 PSH 가 이기면: 이 데이터에서는 평활이 견고 추정에 더하는 몫이 있다고 쓴다.
- 조건 M 결과는 공개 UWB 데이터에서의 결측 결과 재현으로 결측 절에 짧게 넣는다. 예상과 다르면 그대로 쓴다.
