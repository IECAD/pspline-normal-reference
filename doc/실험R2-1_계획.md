# 실험 R2-1 계획: 학습 기록이 불완전할 때의 측위 효과 (사전 등록)

작성: 2026-11-06 · 상위: Mathematics 2차 심사 심사자 2 ("evaluating effects on positioning accuracy or localization reliability has been ignored"), 저자 결정 (나) 2026-11-06 · 기반: `doc/실험7_계획.md`(측위 효과, 등록 2026-10-11), `experiments/exp6_comparators_missing.py`(결측 조건) · 대상: 이 저장소에서 작업하는 사람과 AI 어시스턴트

## 0. 질문
- 실험 7은 학습 기록이 완전할 때 노드별 정상 기준의 탐지를 측위에 반영하면 위치 오차가 준다는 것을 보였다(정답 노드 −49 ~ −63 %, 추정 노드 −21 ~ −23 %, D1 주입). 거기서 P-스플라인과 셀 평균은 대등했다.
- 이 논문의 주제는 학습 기록이 불완전할 때다. R2-1은 묻는다: **학습 칸이 빠졌을 때, 탐지 기준의 선택(P-스플라인, 단위 평균으로 채운 셀 평균, 행 평균 채움, 보간)이 측위 오차를 바꾸는가?**

## 1. 등록 전에 본 값 (미리 밝혀 둘 것)
- 실험 7의 모든 결과(정답·추정 노드, P1–P4, `results/exp7/`)와 원고에 보고된 결측 탐지 결과(실험 6, R1-4: 단위 평균 채움 셀 평균은 50–74 % 결측에서 AUC-PR 0.52–0.77로 무너지고, 채움·보간은 P-스플라인과 운용 임계값에서 대등)를 모두 봤다.
- 결측 조건에서 측위를 돌린 적은 없다. 이 등록 전에 이 실험의 코드를 실데이터로 실행하지 않았다.

## 2. 설계
### 2.1 데이터와 이상
- **P1 (주):** D1 세 공간, 실험 7과 같은 검증·테스트 윈도우, 주입 SC1(앵커 1개)·SC2(2개 동시) 주, SC3 보조. 주입 시드는 `configs/exp3.yaml`.
- **P2 (보조, 테스트만, 서술):** D1 실제 NLOS 파일 4개 (실험 7 P2와 같음).
- **P3 (보조, 서술):** D2 주입 SC1m·SC2m·SC3m, 실험 7 P3와 같은 규칙(기하 NLOS 앵커는 측위에서 뺌, LOS 앵커 4개 이상인 스텝만, LS 만 주 해법).

### 2.2 학습 결측 조건 (탐지 기준의 학습 몫에만)
- 실험 6·R1-4와 같은 생성기와 시드(`exp6_comparators_missing.apply`):
  - D1: 기준(결측 없음), C 무작위 r = 0.5·0.7 (조건 시드 0–2), D 버스트 π = 0.7·L = 4 (시드 0–2), P 실제 손실 이식 P3 층 (시드 0–2).
  - D2: 기준, C r = 0.7 (시드 0–2).
- 마스크는 탐지기의 학습 윈도우에만 적용한다(Composer 표준화와 기준 적합 모두). 보정(검증) 윈도우와 평가 윈도우는 그대로 둔다.
- **측위 쪽 값은 고정한다:** 앵커 좌표, 높이 차, 편향 b_a, σ_a 는 실험 7과 똑같이 완전한 학습 데이터에서 구한 값이다. 바뀌는 것은 탐지 기준뿐이다.

### 2.3 탐지기 (soft 가중, 실험 7 검증 판정 그대로)
| 이름 | 기준 | 비고 |
|---|---|---|
| PS | P-스플라인 (F01, K_t = T = 12, SAP) | 제안 |
| CG | 셀 평균 (단위 평균 채움; 원고의 "cell mean (unit fill)") | 실험 7의 cell |
| CF | 셀 + 노드 행 평균 채움 | |
| CI | 셀 + 선형 보간 | |
- 앵커 점수 = 그 앵커 행들의 최댓값, 임계값 = 각 기준의 검증 97.5 백분위, soft 가중 w = 1 (A ≤ θ), (θ/A)² (A > θ).
- **노드 지정 두 가지:**
  - **추정 노드 (주, D1):** 실험 7 추가 비교의 2단계 절차. 탐지 미반영 LS 해의 윈도우 중앙값에 가장 가까운 학습 노드 → 그 탐지기 점수 → soft 가중 LS 해의 중앙값으로 다시 가장 가까운 노드 → 최종 점수. **각 탐지기는 자기 점수로 2단계를 돈다** (실험 7 추가 비교의 cell-soft 는 PS 점수로 2단계 노드를 골랐다 — 이 점이 다르다).
  - **정답 노드 (참고, D1·D2):** 태그가 있는 학습 노드의 모델로 점수를 낸다 (순환 가정, 상한 참고값).
- 구성: none(탐지 미반영) + {PS, CG, CF, CI} × {추정 노드, 정답 노드} soft. D2는 정답 노드만 (실험 7과 같은 이유).

### 2.4 해법과 지표
- 해법: LS, WLS (주), Huber, EKF(결합 갱신) (서술). `src/positioning/solvers.py` 그대로 (실험 7 안전장치 포함).
- 지표: 스텝별 위치 오차, 단위를 합친 RMSE (모든 스텝 = 주), P90, 이상 스텝·정상 스텝 RMSE.
- 개선율 = (RMSE_none − RMSE_X) / RMSE_none. 상대 차이 = (RMSE_X − RMSE_PS) / RMSE_PS.
- 짝 단위: P1 (공간, 시나리오, 주입 시드, 조건 시드). 결측 조건 계열마다 조건 시드 3개를 합쳐 판정한다.
- 구간 (서술): 공간(방)을 군집으로 하는 2단계 군집 부트스트랩 (B = 5000) — 상대 차이의 95 % 구간. 방이 3개라 구간은 참고용이다.

## 3. 판정 (테스트 한 번; 검증은 실행 점검용으로 먼저 돌리고 고르는 것은 없다)
D1 P1, SC1·SC2 각각, LS·WLS 각각, **추정 노드**:
- **R2-1a (결측에서도 측위 이득 유지):** 각 결측 계열(C 0.5, C 0.7, D, P)에서 PS-soft 개선율 ≥ 5 % 이고, 짝 단위의 80 % 이상에서 PS-soft RMSE < none. 네 계열 × 두 시나리오 × 두 해법 모두 충족이면 "예".
- **R2-1b (단위 평균 채움 기준은 측위 이득을 잃는다):** 각 결측 계열에서 CG 의 상대 차이 > +2 % 이면 "PS 우위", |상대 차이| ≤ 2 % "대등", < −2 % "CG 우위". 시나리오·해법별로 적는다.
- **R2-1c (단순 채움·보간):** CF·CI 에 같은 규칙.
- 정상 스텝 RMSE 가 none 보다 2 % 넘게 나쁘면 "오경보 비용"으로 적는다.
- 기준(결측 없음) 조건은 판정하지 않고 실험 7과의 일치를 확인하는 데 쓴다 (PS 정답 노드는 실험 7 값과 같아야 한다; 다르면 테스트 전에 원인을 찾는다).
- 정답 노드 결과, P2, P3, Huber·EKF 는 같은 지표로 서술만 한다.

## 4. 실행 전 예상 (추정)
- R2-1a: 충족. 결측 70 %에서도 PS-soft(추정 노드) 개선율은 결측 없는 값(21–23 %)에 가깝다 (R1-4에서 P-스플라인 탐지는 결측 70 %에서도 0.93 수준).
- R2-1b: C 0.7·D·P 에서 PS 우위 (+2 % 초과). CG 는 결측 70 %에서 탐지가 무너져(AUC-PR 약 0.57) soft 가중이 거의 정보를 주지 못하거나 정상 앵커까지 낮춘다. C 0.5 에서도 PS 우위일 것이다.
- R2-1c: CF·CI 는 모든 계열에서 PS 와 대등 (2 % 안). 운용 임계값에서 탐지 F1 이 같았기 때문이다.
- 정답 노드에서도 같은 방향, 크기는 더 크다.
- P3 (D2): 19 윈도우라 결측 70 %에서도 빈 칸이 거의 없어 네 기준이 대등하다.
- 오경보 비용: PS·CF·CI 에서는 없음. CG 는 정상 스텝에서도 none 보다 나빠질 수 있다.
