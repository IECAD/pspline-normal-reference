# 실험 4 계획: 구성요소 ablation → 최종 모델 확정 (사전 등록)

작성: 2026-10-10 · 상위: `doc/PROJECT_BRIEF.md` 5.2절 실험 4, `doc/결정기록_실험3이후.md` · 대상: 이 저장소에서 작업하는 사람과 AI 어시스턴트

이 문서의 1–5절은 실험 4를 실행하기 **전에** 적었다. 결과는 `results/exp4/report.md`에 적는다. 규칙을 바꿔야 하면 바꾼 사실과 이유를 보고서에 따로 적는다.

**미리 밝혀 둘 것.** 시간 기저 끝점 C05(= Z1)와 C06(= Z2)의 D1·D2 검증 결과는 이 규칙을 적기 전에 이미 봤다 (`doc/결정기록_실험3이후.md` 4.2절). 그래서 선택 규칙은 그 결과와 무관하게 설명할 수 있는 형태로 정했다. 규칙의 원칙은 "근거가 있을 때만 바꾸고, 어느 데이터에서도 나빠지지 않을 것"이다 (2절). 테스트 세트는 지금까지 F01·B0(실험 3)에서만 썼고, 기준선 사다리에서는 쓰지 않았다.

## 1. 기준과 구성

기준 = **F01** (V5·S1·O1·T4, D1은 V1; cubic B-spline K_t = 8, 2차 차분, λ_t는 SAP로 노드마다 하나를 모든 행이 공유, 점수 A_R). 한 축씩 바꾼다. 합성(①–④), 분할, 마스크, 주입 시나리오·시드, 임계 규칙(검증 97.5 백분위), 앵커 점수(행 최댓값)는 모두 F01과 같다.

### adaptive K_t (C04)
- 후보 K마다 공간(환경)의 모든 노드를 F01 방식으로 적합하고, BIC_K = Σ_노드 [n·log(RSS/n) + log(n)·ED]를 계산한다.
  - n은 관측 셀 수, ED는 유효 자유도 tr(C⁻¹A)다.
  - 학습 데이터만 쓴다.
- BIC_K가 가장 작은 K를 고른다.
- BRIEF 2.4의 계산시간 penalty는 노드당 적합이 0.03 s 이하라 넣지 않는다.

### 보조 점수 정의 (BRIEF 2.5 초안의 구현)
- 테스트 윈도우 하나를 같은 기저와 그 노드의 λ_t로 행마다 따로 적합한다. 관측 셀(W > 0)만 쓴다: θ_test = (Bᵀ diag(w) B + λ_t DᵀD)⁻¹ Bᵀ diag(w) y.
- **A_C (제어점 편차):** Δθ = θ_test − θ_node.
  - 검증 윈도우의 Δθ로 (행, 기저)별 μ·σ를 구한다.
  - 표준화한 |Δθ|를 기저 가중으로 시간에 옮긴다: A_C(s,t) = Σ_k B[t,k]·|Δθ_sk − μ_sk|/σ_sk / Σ_k B[t,k].
- **A_K (곡률 변화):** κ = Δ²_t(B θ_test − M_node), 시간 방향 2차 차분이다.
  - 길이 T − 2를 가운데에 놓고, 양 끝은 가장 가까운 값으로 채운다.
  - 검증 윈도우로 행별 μ·σ를 구해 A_K = |κ − μ|/σ로 둔다.
- 결합 점수 = 선택한 점수들의 셀별 최댓값이다. 임계값은 결합 점수의 검증 97.5 백분위로 정한다.

## 2. 선택 규칙 (검증 세트만)

- **판정 데이터:** D1 주입 SC1–SC3 (공간 3 × 시나리오 3 × 시드 5 = 45쌍)과 D2 다지표 주입 SC1m–SC3m (환경 4 × 3 × 5 = 60쌍). D2 거리만 주입은 함께 보고만 한다.
- **비교 단위:** 같은 공간(환경)·시나리오·시드끼리 짝지은 AUC-PR 차이의 평균 Δ.
- **허용오차:** 실험 3과 같다. tol_D1 = 0.0165, tol_D2 = 0.0171 (`results/exp3/selection.json`). HitRate·Smearing은 0.01.
- **"이긴다"의 정의 (근거가 있을 때만 바꾼다):** 선택지 o가 축의 현재값(F01의 값)을 이기려면 두 조건을 모두 만족해야 한다.
  - 한 데이터 이상에서 Δ > tol
  - 두 데이터 모두에서 Δ ≥ −tol
- **축별 선택**
  1. 현재값을 이기는 선택지가 없으면 현재값을 유지한다.
  2. 여럿이 이기면 두 데이터의 평균 Δ가 가장 큰 것을 고른다.
  3. 평균 Δ가 0.0165 이내로 동률이면 HitRate(두 데이터 평균, 높을수록), 그다음 Smearing(낮을수록), 그다음 단순함 순서로 정한다.
- **단순함 순서**
  - ⓐ 2차 < 1차
  - ⓑ 상수 < 셀 평균 < K10 < K12 < adaptive
  - ⓒ 수동 < 행별 SAP
  - ⓓ A_R+A_C < A_R+A_K < 세 점수 모두
- **차선 (M02용):** 축마다 "이기는" 선택지 중 두 번째. 없으면 두 데이터 평균 Δ가 가장 큰 비열등(두 데이터 모두 Δ ≥ −tol) 선택지. 그것도 없으면 현재값.

## 3. 결합과 최종 모델

- **M01** = 축별 선택의 결합이다.
  - 시간 기저가 상수나 셀 평균으로 선택되면 ⓐ·ⓒ 축은 의미가 없으므로 뺀다.
  - 점수 축(ⓓ)은 그대로 적용한다.
- **상호작용 확인:** M01을 검증에서 돌린다. 축별 선택 단독 구성(C**) 중 2절의 정의로 M01을 "이기는" 것이 있으면, 그중 두 데이터 평균이 가장 큰 단독 구성을 최종으로 한다. 이 사실은 보고한다. 없으면 M01이 최종이다.
- **최종 모델은 BRIEF 2절의 기본안이 된다.** 기본안이 P-spline이 아닌 끝점(상수·셀 평균)이 되더라도 성능 규칙대로 따르고, 주장은 `doc/결정기록_실험3이후.md` 2절의 조정표로 고친다. 방법의 정체성을 지키려고 규칙을 바꾸지 않는다.

## 4. 테스트 (최종 확정 후 한 번)

- 대상: C00–C15, M01, M02 (D1 주입, D1 실제 NLOS A′ 보조, D2 다지표·거리만 주입).
- 같은 시점에 **실험 1의 단순 기준선 부분**(Z0, Z0s, Z1, Z1t, Z2)도 테스트에서 한 번 돌린다.
  - 판정은 `doc/결정기록_실험3이후.md` 2절 기준을 최종 모델에 적용한다.
  - 주 기준선은 D1 Z1, D2 Z2다. 최종 모델이 기준선과 같은 구성이면 "동일"로 적는다.
- 테스트 결과로 선택을 바꾸지 않는다.

## 5. 실행 전 예상 (추정)
- D1: 대부분의 축에서 차이가 tol 이내일 것이다. λ_t가 1e5–1e6이라 거의 직선이다.
- D2: 기저 수를 늘리면(K12) 또는 셀 평균이면 F01보다 높을 것이다 (C06 = Z2는 이미 +0.019를 봤다). 차분 차수와 λ 모드의 영향은 작을 것이다.
- 보조 점수: 근거가 없다. 예상하지 않는다.
