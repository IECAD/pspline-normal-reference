# 실험 R1-6 계획: 다른 센서(Wi-Fi RSS)에서 같은 구조 검증 — D7 UJI (사전 등록, 2026-10-28)

작성: 2026-10-28 · 상위: `paper/mathematics/revision_r1/심사의견_정리.md`(결정 D5 (가)), `data_ext/D7_uji/STRUCTURE.md`(구조 점검, 사전 등록 전에 본 값 전부) · 대응 의견: **C5** · 대상: 이 저장소에서 작업하는 사람과 AI 어시스턴트

## 0. 목적
- 심사자 C 는 증거가 UWB 에 몰려 있다고 지적했다(C5). 원고의 주장은 "위치마다 정상 기록이 반복되는 다변량 센서"이다(4.7절). 그 주장을 **같은 구조의 다른 센서**에서 확인한다.
- UJI 데이터는 고정 송신기(Wi-Fi AP)의 신호를 같은 기준점에서 반복 측정한 것이라 UWB(고정 앵커, 같은 지점 반복 측정)와 구조가 같다. 위치의 의미가 다른 데이터(대기질 측정소의 일주기 등)는 주장 확장이라 이번에 쓰지 않는다.
- 결측은 자연 발생이고 **값 의존**(약한 AP 가 안 들림)이다. 지금까지 실데이터에서 보지 않은 결측 기제다.

## 1. 데이터와 틀 (D7)
- 출처·라이선스·파일 지문: `data_ext/D7_uji/STRUCTURE.md`. 데이터 CC BY 4.0. 내려받은 MATLAB 스크립트는 실행하지 않는다. 로더 `src/data/d7_uji.py`(새로 작성)는 csv 만 읽는다.
- **1개월째만 쓴다.** 학습 세트 trn01–trn15(같은 48 기준점), 같은 기준점의 테스트 세트 tst01·tst05.
- **노드 = (기준점, 방문).** 세트마다 기준점 하나에 연속 스캔 6회 블록이 두 개 있다. 파일 순서에서 먼저 나온 블록을 방문 a, 나중 블록을 방문 b 로 한다 → 노드 96개.
- **창 = 한 블록의 연속 스캔 6회 (T = 6).** 스캔 간격 약 3.5 s.
- **단위 = 층**(3층, 5층). 표준화(S1)는 단위의 학습 칸으로 한다(UWB 실험과 같은 규칙).
- **행 = AP.** 노드마다 학습 스캔의 50 % 이상에서 들린 AP 를 그 노드의 행으로 쓴다(학습 데이터로만 정함). 단위의 행 집합은 노드 행의 합집합이고, 노드에 속하지 않는 행은 점수·라벨에서 뺀다(D6 와 같은 방식).
- **값:** RSS(dBm). +100(미수신) = 결측 칸.
- **분할(시간 순):** 학습 trn01–trn10 (노드당 창 10), 검증 trn11–trn13 (3), 테스트 trn14·trn15·tst01·tst05 (4). tst01·tst05 의 블록 구조가 trn 과 다르면 그 세트는 빼고 테스트는 trn14–15 만 쓴다(실행 전에 정해 둠).

## 2. 이상 주입 (검증·테스트 창)
- 창마다 확률 0.5 로 사건 하나. 시나리오: W1 AP 행 1개 · W2 AP 행 2개 동시 · W3 짧은 사건(스캔 1–2개).
- 유형: 감쇠 지속(창 전체, 40 %) 또는 감쇠 구간(스캔 2–4개, 60 %). 크기: 관측값에서 Δ 를 뺀다. **Δ = U(3, 6) × (그 노드·행의 학습 RSS 표준편차)** — 물리 단위(dB)를 따로 가정하지 않고 행의 잡음 척도에 맞춘다.
- 주입 칸이 그 창에서 관측되지 않은(미수신) 칸이면 라벨 NaN.
- 주입 seed: 검증 142–146, 테스트 42–46 (UWB 실험과 같은 번호 규칙).

## 3. 참조와 조건
- 참조(탐지기는 self): GM = 단위 전체의 전역 셀 평균(노드 구분 없음, 노드 뱅크 효과 확인용) · CG · CF · CI · NM · PS · PS1 · PSH · PS1H (기호는 `doc/실험R1-5_계획.md` 2절과 같음). 조정할 매개변수가 없어 선택 단계는 없다.
- 조건:
  - **N 자연 결측(주).**
  - M 추가 결측: 학습 칸에 MCAR r ∈ {0.5, 0.7} 를 더함(조건 seed 0–2).
  - F 창이 적을 때: 학습 trn08–trn10 만(노드당 3).
- 지표: 셀 AUC-PR(주), HitRate, 실현 오경보율(칸·그룹).

## 4. 허용오차와 판정
- 허용오차는 실험 1 의 규칙을 그대로 쓴다: tol = max(검증에서 CG 의 주입 seed 간 SD, 0.01). **검증 실행 뒤, 테스트 전에** 값을 이 문서에 적는다.
- 짝 = (단위, 시나리오, 주입 seed[, 조건 seed]). 판정은 검증, 테스트는 한 번. 군집 부트스트랩의 군집 = 층(2개) — 군집이 둘뿐이라 구간은 참고로만 쓰고 기준점 수준 결과를 함께 보인다.

## 실행 전 수정 (2026-10-28, 코드 작성 뒤·검증 실행 전 — 위쪽은 고치지 않음)
등록 문서가 정하지 않은 구현 세부. 예상·판정 규칙은 바꾸지 않는다.
1. 구조 확인(결과 아님): tst01·tst05 도 trn 과 같은 블록 구조라 테스트는 trn14·trn15·tst01·tst05 4개를 모두 쓴다. 층마다 노드 48(기준점 24 × 방문 2), 단위 행(AP 합집합) 3층 57·5층 53, 노드당 행 중앙값 16·19. 노드당 창 학습 10·검증 3·테스트 4.
2. 행 선택은 조건의 학습 세트로 한다: N·M 은 trn01–10, F 는 trn08–10.
3. 적합은 노드의 관측 칸 전부(선택 밖 행 포함)를 쓰고, 점수·라벨은 노드 선택 행이면서 관측된 칸만 남긴다(D6 와 같은 방식). 표준화 S1 은 단위의 (조건 마스크 뒤) 학습 칸.
4. M 조건 마스크: 학습 관측 칸마다 확률 r 로 지운다, rng = default_rng(2000 + 조건 seed)(실험 6 'C' 계열과 같은 번호 규칙).
5. 주입 rng = default_rng([주입 seed, 시나리오 번호(W1 0, W2 1, W3 2)]). 대상 행 = 노드 선택 행 중 그 창에서 스캔 절반 이상 관측된 행. 주입 크기의 행 SD 는 그 노드·행의 (조건 마스크 뒤) 학습 RSS SD, 없으면 단위 행 SD.
6. GM 은 단위의 모든 창을 노드 하나로 보고 셀 평균 뱅크를 적합·보정·채점한다.
7. 허용오차: 검증 실행 직후 `results/expR1/uji/tolerance.json` 에 자동 기록(규칙 4절), 테스트 전에 이 문서에 옮긴다.

## 6절 구성 변화 결과 (서술, 2026-10-28, `results/expR1/uji/shift_far.csv`)
- 1개월째 학습(trn01–10)·검증(trn11–13) 보정 PS 로 같은 기준점 세트의 정상 칸 실현 오경보율(명목 2.5 %): 검증 2.7 %, 테스트 6.2 %.
- 1개월째 안에서도 세트에 따라 크게 다르다: trn01 15.8 %, trn02 6.8 %, tst01 2.9 %, tst05 16.9 %. 학습 세트(trn01)도 높다 → 한 달 안에서도 정상 RSS 가 시점에 따라 움직이고, 검증 시점과 떨어진 데이터에서 오경보가 는다.
- 2–25개월째(Galaxy S3) 평균 8–12 %, 시간이 지나며 뚜렷이 늘지는 않는다. 25개월째 단말 교체(Galaxy A5) 9.6 % 대 같은 달 S3 11.6 % — 단말 교체가 오경보를 더 키우지 않았다.
- 원고 반영: C7(보정)과 A7(프로토콜 밖에서 정상 프로파일 정렬)에 대한 실데이터 근거. 고정 임계는 시점 이동에 약하므로 현장 적용에서는 주기적 재보정이 필요하다고 쓴다.

## 사후 확인: 테스트 세트의 수집 방향 (2026-10-29, 등록 밖, 판정 변경 없음)
- 실행 뒤에 데이터 논문(Mendoza-Silva et al., *Data* 2018, 3, 3, 6쪽)을 읽었다. 학습 세트와 Test-01–03 은 "Up"(direct)·"Down"(reverse), Test-04·05 는 "Left"·"Right" 방향으로 수집했다. 한 점의 앞 6샘플·뒤 6샘플은 '방문 1·2'가 아니라 두 방향이다. 노드는 (기준점, 블록)이므로 학습·검증·trn14·trn15·tst01 에서는 같은 위치·같은 방향이지만, tst05 에서는 같은 위치·다른 방향이 같은 노드로 비교됐다.
- 등록 판정(U1–U6)은 등록대로 네 세트(trn14, trn15, tst01, tst05)를 합친 값으로 두고 바꾸지 않는다.
- 사후 세트별 분석: `experiments/expR1_6b_uji_by_set.py` → `results/expR1/uji/by_set_test.csv`·`by_set_test.md`. 등록 실행과 같은 주입·시드, 네 세트 합 재현 차이 최대 8.33e-17.
  - 조건 N: 학습 방향 세트(trn14, trn15, tst01) PS AUC-PR 0.848, 실현 셀 오경보율 2.4–2.9 %(참조별, GM 제외); tst05 0.421, 15–17 %.
