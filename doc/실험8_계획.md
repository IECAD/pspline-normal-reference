# 실험 8 계획: 계산 비용 (사전 등록)

작성: 2026-10-11 · 상위: `doc/PROJECT_BRIEF.md` 5.2절 실험 8 (RQ1), 5.4절 비용 지표, 5.5절 "MCU 실측이 없으면 PC 기준으로 한정" · 대상: 이 저장소에서 작업하는 사람과 AI 어시스턴트

## 0. 성격
- 서술 실험이다. 선택·판정 규칙이 없다. 탐지 성능은 실험 1에서 이미 정해졌다. 여기서는 그 구성의 비용만 잰다.
- **PC 기준이다.** MCU 실측은 없다.
  - 측정 기기: AMD Ryzen 7 7800X3D (8코어), RAM 63 GB, NVIDIA RTX 4070 Ti, Windows 11, Python 3.10, PyTorch 2.10, NumPy (BLAS 단일 스레드).

## 1. 대상 모델 (실험 1에서 데이터별로 고른 구성 그대로)
- 제안 PS, 셀 평균(M01), 노드 평균(Z1)
- 1차: PCA, RPCA, OLS, Isolation Forest, LSTM-AE, USAD, 1D-CAE
- 2차: Laplacian-RPCA, RRR, Transformer, 2D Conv-AE, GDN, OmniAnomaly
- 빼는 모델:
  - ST-SSD형 노드별 배경: 선택 구성이 γ = 0이라 PS와 같은 계산이다. FISTA 구성의 추론 시간(PS의 약 40배)은 `results/exp1_stssd/report.md`에 있다.
  - UWB 규칙(RX−FP, 시간이력, oracle): 학습 파라미터가 사실상 없다.
- **측정 단위:** 데이터마다 대표 단위 하나다. D1 강의실(노드당 윈도우가 가장 적음), D2 env1.
  - 딥러닝 CPU 학습이 길어서다.
  - PS·셀 평균의 노드 수와 파라미터 수는 모든 단위에 대해 적는다.

## 2. 지표
| 지표 | 정의 |
|---|---|
| 파라미터 수 | 추론에 저장해야 하는 실수 개수. PS·셀 평균은 노드 수 × (행 × T) + 보정값(행별 μ_R, σ_R, 임계값). nc 입력 모델은 nc 기준(셀 평균 bank)을 함께 더한 값과 모델만의 값을 둘 다 적는다 |
| 메모리 | 파라미터 수 × 4 바이트 (float32 저장 가정, KB) |
| 학습 시간 | 공간/환경 하나의 전체 학습 시간 (합성 제외, nc 기준 포함). **CPU 단일 스레드**가 기준이다. 딥러닝은 GPU 값도 함께 적는다 |
| 추론 시간 | 윈도우 하나씩 넣었을 때(배치 1, 실시간 운용 가정)의 중앙값 ms. 같은 평가 윈도우 최대 200개, CPU 단일 스레드가 기준이다. 배치 전체 처리의 윈도우당 시간도 함께 적는다 |
| 추론 연산 수 (PS만, 해석적) | 윈도우당 S·T 칸마다 뺄셈 2, 나눗셈 1, 절댓값 1. 앵커 최댓값 비교 S·T |

- 합성(comp.transform)은 모든 모델이 공유하는 전처리라 따로 한 번 잰다.

## 3. 실행 전 예상 (추정)
- PS의 추론은 윈도우당 0.05 ms 미만(CPU, 배치 1)이다. 딥러닝(CPU, 배치 1)보다 10배 넘게 빠를 것이다.
- PS 파라미터 수는 노드 수에 비례하고, 셀 평균과 같다 (K_t = T).
  - 노드가 많은 D2(경로 위치)에서는 PCA·OLS보다 클 것이다.
  - 표에 "노드 수에 비례"를 함께 적는다.
- PS 학습(SAP)은 셀 평균보다 느리다. 그래도 노드당 수십 ms 이내일 것이다.
- 출력: `results/exp8/`

---

## 결과 (2026-10-12, 덧붙임)
- PS 추론(CPU, 배치 1): 0.040 ms (D1), 0.068 ms (D2). 배치 전체는 0.005 ms/윈도우다.
- PS 파라미터: 노드 수 × 행 × T에 비례한다 (D1 548–1,724개, 2–7 KB).
- PS 학습: 노드당 5–21 ms다.
- 딥러닝(CPU, 배치 1) 대비 4–3,800배 빠르다. 예상과 달리 1D-CAE·USAD·2D Conv-AE와는 4–6배 차이뿐이다 (배치 1의 Python 호출 비용).
- 첫 실행은 RBC^φ의 파라미터 수 계산이 빠져 중단됐다. 고친 뒤 다른 작업 없이 다시 돌렸다.
- 보고서: `results/exp8/report.md`.
