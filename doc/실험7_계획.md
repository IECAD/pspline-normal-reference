## 2. 측위 모델 (2D, 높이 차는 알려짐)
- **측정식:** d_a = sqrt((x − x_a)² + (y − y_a)² + h_a²) + b_a + ε_a
  - D1: h_a = dz, b_a = 앵커별 편향. 공간마다 정상 파일의 학습+검증 사이클로 적합한 값이다 (`cache/d1_geometry.json`, `src/data/labels.py`). 앵커 (x, y)는 `configs/data.yaml`.
  - D2: h_a = Z_TAG − Z_ANCHOR (GT), b_a = 학습 몫 LOS 셀의 (RANGE − 실제 거리) 중앙값 (환경·앵커별).
  - σ_a: 정상 학습 몫에서 앵커별 (측정 − 실제 거리 − b_a)의 표준편차.
- **해법 4종** (모두 같은 측정·가중치 입력):
  - **LS:** Gauss-Newton. 가중치 = 탐지 가중치만. 초기값 = 앵커 중심, 최대 30회.
  - **WLS:** 가중치 = 탐지 가중치 / σ_a².
  - **Huber:** WLS에 IRLS Huber 가중 (표준화 잔차 기준 δ = 1.345)을 곱한다.
  - **적응 EKF:**
    - 상태 (x, y), 랜덤워크 과정 잡음 q (D1 0.05 m, D2 0.3 m = 경로 간격).
    - 측정 잡음 R_a = σ_a² / 탐지 가중치.
    - 혁신 기반 적응: 정규화 혁신 제곱이 6.63(χ²₁ 99%)을 넘으면, 그 값이 6.63이 되도록 R_a를 키운다.
    - 윈도우마다 첫 스텝의 WLS 해로 초기화한다 (P₀ = 1 m²·I). ~~앵커별로 순차 갱신한다.~~ → **결합 갱신** (아래 주).
    - **실행 전 수정 (2026-10-11, 실제 데이터를 돌리기 전 합성 점검 결과):**
      - 순차 갱신에서는 먼저 갱신한 앵커가 상태를 끌고 간다. 그러면 뒤의 정상 앵커가 게이트에 걸린다.
      - 합성 점검: 앵커 4개 중 1개에 +1 m 상수 편향을 넣었다. 순차 EKF 1.21 m, WLS 0.57 m, 결합 EKF 0.51 m였다.
      - 그래서 주 해법은 결합 갱신으로 바꾼다. 결합 갱신은 예측 상태에서 앵커마다 게이트를 판정하고 한 번에 갱신한다.
      - 순차 갱신(원안)은 보조 해법 EKFseq로 함께 보고한다.
- **실행 중 수정 (2026-10-11, 첫 검증 실행에서 발견, 테스트 전):**
  - 수치 안전장치를 넣고 검증을 다시 돌린다. 모든 해법·반영 구성에 같게 적용한다.
  - 원인: D2 다지표 주입 풀(실험 3·5의 실제 NLOS 서명)에는 거리 변화가 음수인 것도 있다 (최소 −9.3 m, 중앙값 +1.25 m).
  - 가중치가 큰 앵커에 −8.8 m가 들어가자 Gauss-Newton이 수천 m 밖으로 발산했다 (D2 env2, 탐지 미반영 WLS RMSE 76,014 m). EKF도 그 해로 초기화돼 무너졌다.
  - 안전장치 (`src/positioning/solvers.py`):
    1. 편향 보정 거리 하한 0
    2. Gauss-Newton 한 걸음 최대 1 m, 반복 최대 50회
    3. 위치를 앵커 경계 상자 ± 3 m 안으로 자름 (EKF 포함)
  - 판정 규칙은 바꾸지 않는다.
  - 첫 검증 실행의 D1 결과(soft 유지, LS·WLS 개선율 52–57 %)는 이미 봤다.
- D2 env0은 LOS 앵커가 4개 이상인 스텝이 없어 P3에서 빠진다 (규칙 그대로).
- 관측이 없는 앵커(NaN)는 뺀다. 쓸 수 있는 앵커가 3개 미만인 스텝은 평가에서 뺀다 (모든 구성에서 같은 스텝).

## 3. 탐지 반영
| 구성 | 정의 |
|---|---|
| none | 탐지 미반영 (가중치 1) |
| X-hard | 앵커 점수 A > 임계값이면 뺀다. 남은 앵커가 3개 미만이면 점수가 낮은 3개를 쓴다 |
| **X-soft (BRIEF 기본)** | w = 1 (A ≤ 임계값), w = (임계값 / A)² (A > 임계값) |
| oracle-hard | 정답 이상 앵커를 뺀다 (같은 3개 규칙). 상한 참고값 |

- X ∈ {PS, cell}. 앵커 점수 = 그 앵커 행들의 최댓값 (D1은 거리 1행). 임계값 = 각 모델의 검증 97.5 백분위.

## 4. 지표
- 스텝별 위치 오차 e = ‖p̂ − p‖ (m).
- RMSE, P90, 개선율 = (RMSE_none − RMSE_구성) / RMSE_none. 개선율은 같은 해법끼리 비교한다.
- 모든 스텝(주), 이상 스텝(정답 이상 앵커가 하나라도 있는 스텝), 정상 스텝으로 나눠 본다.
- 짝 단위: P1 (공간, 시나리오, 시드), P3 (환경, 시나리오, 시드), P2 (파일).

## 5. 판정
- **검증에서 정하는 것 (하나):** 기본 반영 방식 soft / hard.
  - hard가 P1 검증 SC1·SC2 모두에서, 해법 4개 중 3개 이상에서 PS-soft보다 RMSE가 5% 넘게 낮으면 기본을 hard로 바꾼다.
  - 그렇지 않으면 soft를 유지한다.
- **테스트 (한 번, 주장):**
  - RQ6 "예"(해법별): P1 테스트 SC1·SC2 각각에서 PS-기본의 모든 스텝 RMSE 개선율이 ≥ 5%이고, 짝 단위의 80% 이상에서 RMSE가 낮아야 한다.
  - **LS와 WLS 둘 다 충족하면 RQ6에 "예"라고 쓴다.**
  - Huber·EKF는 "견고 해법 위의 추가 이득"으로 따로 서술한다 (같은 기준).
  - PS vs cell: RMSE 상대 차이 2% 안이면 대등.
  - 정상 스텝 RMSE가 none보다 2% 넘게 나빠지면 "오경보 비용"으로 적는다.
  - P2·P3는 같은 지표로 서술만 한다.

## 6. 실행 전 예상 (추정)
- LS·WLS: PS-soft 개선율이 SC1·SC2 모두 ≥ 5%이고, 이상 스텝에서는 20% 이상일 것이다.
- Huber·EKF:
  - 이미 이상치 일부를 처리해서 개선이 더 작을 것이다.
  - 다만 SC2(앵커 4개 중 2개 오염)에서는 Huber도 실패하기 쉬워 탐지 반영 이득이 클 것이다.
- soft ≥ hard일 것이다. 앵커가 4개라 빼면 기하가 나빠진다 (BRIEF 2.7). 따라서 soft가 유지될 것이다.
- PS ≈ cell (2% 안).
- PS-기본과 oracle-hard의 RMSE 차이는 10% 안일 것이다.
- P2 (실제 NLOS): 개선이 작거나 없을 수 있다. 강의실 LOS의 포인트별 고정 오차(약 0.2 m)가 크고, 실제 NLOS의 크기·지속이 주입과 다르다.
- P3 (D2, LOS 앵커 4–8개): 앵커가 많아 LS도 덜 무너진다. 개선율은 D1보다 작을 것이다.

## P4. D2 실제 NLOS 측위 (사전 등록, 2026-10-12, 실행 전)

**질문.** 라벨 누수 없는 탐지를 측위에 반영하면, 실제 NLOS(D2, 기하 라벨, GT 좌표)에서 위치 오차가 주는가? P3는 기하 NLOS 앵커를 정답으로 빼고 주입 이상만 봤다. P4는 실제 NLOS 앵커를 그대로 둔다.

**미리 밝혀 둘 것.**
- 5-3(3-B 근거 5/8, 3-C 4/4)과 P1–P3 결과는 이미 봤다.
- D2에서 σ 가중 해법(WLS, Huber, EKF)이 거울 해에 빠지는 문제도 이미 봤다 (P3). 그래서 주 해법을 LS로 미리 정한다.

### 구성
- **측위 시점:** (환경, 경로 위치, 반복 k)마다 앵커 8개 거리 하나다. 평가 반복 k 25–30 (5-3과 같음).
- **기하:** 앵커 3D 좌표, 높이 차 = Z_TAG − Z_ANCHOR (GT), 2D 해다.
  - 앵커별 편향 b_a와 σ_a는 학습 반복(k 0–18)의 LOS 셀에서 구한다. 방향별 학습 절반 위치만 쓴다.
- **탐지기 → soft 가중 (w = (임계/A)², A > 임계일 때):**

| 구성 | 정의 | 누수 |
|---|---|---|
| none | 반영 없음 | — |

### 판정 (테스트 한 번, 선택 없음)
- **B1-soft의 LS RMSE 개선율 ≥ 5 %이고 짝 단위 80 % 이상에서 개선**이면, "누수 없는 탐지를 반영하면 D2 실제 NLOS에서도 측위 오차가 준다"로 쓴다.

### P4 실행 중 수정 (2026-10-12)
- 첫 실행은 무효다. 학습 절반 위치에서 LOS 셀이 하나도 없는 앵커는 편향 b가 NaN이 되어, 그 앵커를 쓰는 측위 해가 모두 NaN이 됐다. 그 시점들이 집계에서 빠졌다 (반영 없음 486개만 남음, 정답 제외는 906개).
- 수정한 대체값:
  - 그런 앵커의 편향은 다른 앵커 편향의 중앙값, σ는 다른 앵커 σ의 중앙값으로 둔다.
  - B1 탐지 통계는 학습 절반의 앵커 공통 통계로 둔다.
  - 라벨 사용 범위는 바꾸지 않았다.
- 첫 실행의 (무효) 수치는 봤다: 반영 없음 LS 1.18 m, B1 −0.6 %, 정답 제외 −6 %. 판정 규칙은 바꾸지 않고 수정본을 한 번 다시 돌린다.

### P4 결과 (2026-10-12, 수정본 한 번, `results/exp7/d2_real/summary.md`)
- **주 판정 충족:** 공통 시점(1,872개), LS, B1-soft는 RMSE 0.981 → 0.915 m (−6.7 %), (환경, k) 단위 21/24에서 개선.
