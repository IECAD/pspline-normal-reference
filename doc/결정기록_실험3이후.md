### 열어 두는 것
1. **T1·T2·T3, O2·O3·O4 구현은 그대로 둔다** (`src/model/compose.py`). B0 설정(`configs/exp3.yaml`)도 그대로 둔다.
2. **센서 방향 평활의 재검토 조건 (H7, 사전 등록).** 이동 궤적 데이터(D3)를 다루게 되면, 실행 전에 다음을 적고 검증 세트로 판정한다.
   - 가설: 센서 방향 평활 이득 (T2 − T4)이 허용오차보다 크다.

   - H7이 지지될 때만 "센서 간 공변동이 있는 조건에서 센서 방향 평활이 유효"라는 조건부 주장을 쓴다.
3. **기여 1 문구는 실험 4–5 결과에 따라 기여 2와 합칠 수 있다.**
4. 엄격 해석의 결과(E04)로 바꾸는 것은 테스트를 본 뒤 규칙을 바꾸는 일이므로 하지 않는다. 수치 차이도 0.002다.

### 해석용 확인 (선택에 쓰지 않음, 실행 전에 적은 가설)
- **짝지은 차이 정식 보고** (`analysis/43_exp3_paired.py`): 실험 3 그림의 오차막대는 구성별 시드 간 표준편차라, B0와 짝지은 차이의 불확실성이 아니다 (`experiments/exp3_figures.py:47-57`). 같은 공간·시나리오·시드끼리 짝지은 차이, 양수 비율, Wilcoxon p, 공간별 평균을 따로 낸다.
- **H-M (D2에서 T2가 손해인 이유, 추정):** 센서 penalty는 기하가 정하는 앵커별 수준에 걸리고, 마스크로 빈 셀을 이웃 행 값으로 채운다. 그래서 T2의 검증 잔차 분산이 T4보다 (b) 같은 블록의 이웃 행에 빈 셀이 있는 LOS 셀, (c) 같은 행의 빈 셀에 인접한 LOS 셀에서 크고, (a) 행과 이웃 행이 모두 LOS인 셀에서는 차이가 작을 것이다 (`analysis/44_d2_sensor_smoothing.py`, 검증 세트).

## 2. 결정 2: 단순 기준선 사다리 (사전 등록)

### 정의
모든 구성은 F01과 같은 행 선택(D1 V1, D2 V5), 스케일(S1), 분할, 마스크(D2 LOS 셀), 주입 시드(검증 142–146), 임계 규칙(검증 A_R 97.5 백분위), 앵커 점수(앵커 행 최댓값)를 쓴다. 바꾸는 것은 표의 세 성분뿐이다. 구현은 `NormalSurfaceBank`의 옵션이다 (`src/model/bank.py`).

| ID | 기준 수준 (노드) | 시간 방향 | 잔차 표준화 | 분리하는 것 |
|---|---|---|---|---|
| Z0 | 전역 (공간·환경당 노드 1개) | 상수 | 검증 잔차의 행별 μ_R, σ_R (F01과 같음) | Z1 − Z0 = 노드별 Bank |
| Z0s | 전역 | P-spline (F01과 같음) | F01과 같음 | F01 − Z0s = P-spline 조건에서의 Bank |
| Z1 | 노드별 | 상수 (노드×행 평균) | F01과 같음 | F01 − Z1 = 시간 방향 P-spline |
| Z1t | 노드별 | 상수 | 학습 잔차의 행별 SD, μ = 0 (고전 z-score) | Z1 − Z1t = 표준화 방식 |
| Z2 | 노드별 | 셀 평균 (λ_t = 0 극한, 시간 기저 = 항등) | F01과 같음 | F01 − Z2 = 시간 방향 penalty |
| ZF01 | 노드별 | P-spline | F01과 같음 | F01 재현 확인 (`results/F01`와 같아야 함) |

- Z1은 "1차 차분 + λ_t → ∞", Z2는 "λ_t = 0"과 같은 모델이다. 실험 4의 차분 차수·λ 수동 ablation에서 이 둘을 끝점으로 함께 보고한다.
- D1에서는 윈도우 안 시간 위치에 의미가 없어(정지 측정) Z2는 대조군이다. D2에서는 시간 축이 경로 위치라 Z2가 가장 강한 단순 기준선이다.

### 판정 기준
- 허용오차 ε = 실험 3과 같은 값: **D1 0.0165, D2 0.0171** (`selection.json`의 AUC 허용오차).
- 비교 단위: 같은 공간(환경)·시나리오·시드끼리 짝지은 AUC-PR 차이의 평균. D1은 주입 SC1–SC3 45쌍, D2는 다지표 주입 SC1m–SC3m 60쌍 (거리만 주입 SC1–SC3는 함께 보고).
- 판정: 평균 차이 > ε이면 "우위", |평균 차이| ≤ ε이면 "대등", < −ε이면 "열세". 짝지은 쌍의 양수 비율과 Wilcoxon 부호순위 p를 함께 적는다.
- 주 기준선: D1은 Z1, D2는 Z2 (데이터별로 가장 강한 단순 기준선).

### 결과별 주장 조정 (실험 1 테스트 결과에 적용)
| 결과 | 조정 |
|---|---|
| F01이 우위 | 기여 2를 유지하고 이득 크기를 함께 적는다 |
| 대등 | "정지·반복 측정에서 시간 방향 P-spline은 노드별 평균과 대등"으로 쓴다. 기여 2를 "노드별 정상 모델 + 닫힌 형태 표준화 잔차 프레임워크(노드 평균을 특수한 경우로 포함)"로 낮춘다. 방법 고유의 근거를 실험 5(kriging)와 실험 7(측위)로 옮긴다. "주장하지 않는 것"에 "P-spline이 단순 z-score보다 낫다"를 넣는다. 제목의 "P-spline 정상 곡면"을 다시 검토한다 |
| F01이 열세 | 그대로 보고한다. 기본안 교체는 검증 세트와 사전 규칙으로만 한다 |

기준선이 대등하게 나오면 주입 과제가 쉬운지도 함께 적는다 (D1 Lab·복도 천장 효과, `results/exp3/report.md` 7절 4번).

### 이번 실행 (검증만)의 용도와 예상
- 용도: (1) 구현 확인 (ZF01이 F01과 같은지), (2) 실험 4·1 설계 점검. 이 결과로 F01을 바꾸지 않는다.
- 예상 (실행 전, 추정): D1에서 F01 ≈ Z1 (λ_t가 1e5–1e6이라 직선에 가깝고, 정지 측정에서 기울기 기대값은 0). D2에서 F01 ≈ Z2, F01 > Z1 (경로 위치에 따라 거리가 변함). Z0은 D1·D2 모두 크게 낮음 (위치 간 거리 차이 ≫ 잡음).

### D3 (미결 유지)
현재 D3는 녹화 하나가 노드 하나다 (`src/data/d3.py:115`). 이 정의로는 정상 곡면이 이동 궤적을 따라가지 못한다 (추정). D3를 다루게 되면 실행 전에 모델 정의(위치로 Bank 조회 / 테스트 윈도우 자체 평활 중 무엇인지)와 같은 기준 위치를 쓰는 기준선을 정한다. 1절의 H7도 이때 함께 적는다.

## 3. 결정 3: D2 실제 NLOS 평가 프로토콜 (사전 등록)

### 누수 두 가지 (확인된 사실)
- **라벨 마스크 누수:** 분할을 반복 순서 k로 해서 같은 위치가 학습·테스트에 모두 나오고, 라벨은 위치×앵커마다 고정이다. 학습 때 비어 있던 행이 곧 NLOS다 (셀 AUC-PR 0.994–0.997 vs 마스크 없이 0.425–0.656, `analysis/out/41_check_d2_leakage.txt`).
- **이웃 라벨 누수:** NLOS가 경로를 따라 이어져 있어, 이웃 학습 위치의 라벨이 테스트 라벨을 예측한다 (AUC-PR 0.976–0.999, `results/exp3/report.md` 2절. 재현 스크립트: `analysis/45_d2_leak_precheck.py`).
- 따라서 `results/exp3/table_d2_test_real_holdout.csv`와 `h6_anchor_count.csv`의 `holdout` 행은 누수가 있는 결과다. 인용하지 않는다.

### 설계 후보 (네 가지 모두 열어 둔다)
| 설계 | 내용 | 검증하는 주장 (기여 3) |
|---|---|---|
| 3-A | 경로를 블록으로 나눠 테스트 블록 양옆에 완충 g점을 비우고, 나머지 학습 위치에서 kriging으로 기준 곡면을 만든다. 실제 NLOS 라벨로 평가 | 앵커 단위 위치화 + 실제 NLOS + 미학습 위치. 누수 점검을 통과할 때만 |
| 3-B | 위치와 무관한 지표(RX−FP; 선택적으로 실제 좌표로 만든 거리 잔차 = oracle 표기)의 전역 정상 모델. 경로 앞·뒤 절반으로 공간 분할 | 원시 CIR 없이 앵커 단위 위치화 + 실제 NLOS. kriging은 시험하지 않음 |
| 3-C | 환경 간 일반화 (leave-one-environment-out, 4겹), 위치 무관 지표만 | 새 환경에서의 앵커 단위 위치화 (RQ5 일부) |
| 3-D | 3-A와 같은 공간 홀드아웃 기준 곡면에, 홀드아웃 위치의 LOS 셀에만 인공 주입 (NLOS 셀은 평가 제외). 실제 데이터 보완: D1 복도 10점 (`analysis/out/data_report.md` 7절, 방법 A 라벨만 가능) | 미학습 위치 대응 (kriging). 주입 라벨은 기하와 무관해 이웃 라벨 누수가 구조적으로 없음 |

### 누수 대조군 (모든 설계에서 모델과 같은 셀·분할로 함께 보고)
1. **이웃 라벨 예측기:** 기준 곡면에 쓰는 학습 위치(가장 가까운 K = 4개, 태그 xy 거리)의 같은 앵커 라벨을 거리 역가중 평균한 점수.
2. **마스크 부재 예측기:** 그 K개 이웃 중 같은 앵커가 LOS인 위치가 하나도 없으면 1, 있으면 0. 기준이 비어 있다는 사실이 흘리는 정보를 잰다.
3. **앵커 사전확률 예측기:** 학습 위치에서 계산한 앵커별 NLOS 비율. 누수가 아니라 넘어야 할 하한이다.
4. **무작위 점수:** 양성 비율.

보고: AUC-PR, 양성 비율을 함께 적는다. 모델과 대조군 차이의 신뢰구간은 경로 블록 단위 부트스트랩으로 구한다.

### 사전 점검 (모델 없이, 이번에 실행)
- 3-A: 테스트 블록 길이 10점(3 m), 경로를 블록으로 나눠 블록마다 한 번씩 테스트. 완충 g ∈ {0, 2, 5, 10, 15, 20, 30}점. 환경별로 대조군 1·2의 AUC-PR, 커버리지(K개 이웃 중 같은 앵커가 LOS인 위치가 있는 테스트 셀 비율), 이웃까지 거리 중앙값을 계산한다.
- **3-A 진행 기준:** 대조군 1과 2의 AUC-PR이 모두 **양성 비율 + δ 이하 (δ = 0.05)** 이고 커버리지가 **0.5 이상**인 (환경, g) 조합에서만 3-A를 진행한다. 통과 조합이 없으면 "D2 실제 NLOS를 미학습 위치에서 위치화"는 주장하지 않는다.
- 3-B: 경로 절반 분할(양방향)에서 대조군 1(경계 인접 위치)과 3의 AUC-PR. 같은 기준(δ = 0.05)으로 대조군 1을 판정한다.
- 3-C: 다른 환경의 앵커 사전확률로 만든 대조군 3의 AUC-PR, 환경별 LOS RX−FP 분포(학습 반복 k < 19만, 중앙값·IQR).
- 3-D: 커버리지만 계산한다 (LOS 홀드아웃 셀 중 K개 이웃에 같은 앵커 LOS 위치가 있는 비율).
- 실험 3 위치 홀드아웃(path_idx % 4)의 이웃 라벨 AUC-PR을 재현한다.

### 진행 순서 (사전 점검 결과와 관계없이 정한 것)
- 3-B를 실제 NLOS 주 프로토콜로, 3-C를 강건성 확인으로, 3-D를 kriging 프로토콜로 실험 5에 넣는다. 3-A는 진행 기준을 통과한 조합에서만 넣는다.
- 기여 3은 "실제 NLOS 앵커 단위 위치화"(3-B, 3-C, 통과 시 3-A)와 "미학습 위치 대응"(3-D, D1 복도, 통과 시 3-A)으로 나눠 주장한다.

## 4. 결과 (2026-10-10 실행, 1–3절을 적은 뒤)

### 4.3 결정 3: 사전 점검 (`analysis/out/45_d2_leak_precheck.txt`)

- **실험 3 홀드아웃 재현:** 이웃 라벨 AUC-PR env0 0.991, env1 0.997, env2 0.976, env3 0.999. 보고서 2절의 0.976–0.999가 재현됐다 (이전 "미확인" 해소).
- **3-A: 진행 기준을 통과한 (환경, g) 조합이 없다.**
  - env0·env3: 누수 대조군은 env0 g ≥ 10, env3 g ≥ 15에서 기준 안으로 들어오지만, 그 g에서 커버리지가 0.31–0.44로 0.5에 못 미친다.
  - env1: 커버리지는 0.83–0.86이지만, g = 30에서도 이웃 라벨 AUC-PR 0.487로 양성 비율 0.250 + 0.05를 넘는다.
  - env2: 커버리지 0.55–0.59. 이웃 라벨 AUC-PR이 g = 30에서도 0.633으로 0.574를 넘는다.
  - → 사전 기준대로 **3-A는 진행하지 않는다.** "D2 실제 NLOS를 미학습 위치에서 위치화"는 주장하지 않는다.
- **3-B:**
  - 이웃 라벨 대조군이 8개 분할 방향 중 6개에서 기준을 넘었다. 통과한 것은 env0 뒤→앞, env3 뒤→앞뿐이다.
  - 앵커 사전확률 대조군은 0.539–0.928이다 (env1 앞→뒤 0.928, 양성 비율 0.203).
  - **사후 해석 (결과를 본 뒤 적음):** 3-B 모델은 위치별 기준을 쓰지 않으므로 이웃 라벨은 점수 경로가 아니다. 그러나 라벨이 공간적으로 예측 가능하고 앵커 정체만으로도 AUC-PR이 높다. 그래서 다음 조건을 둔다.
    - 3-B 결과는 모델이 **같은 셀에서 이웃 라벨·앵커 사전확률 대조군보다 모두 높을 때만** 근거로 쓴다.
    - 3-B 모델에는 공간 이웃을 쓰는 성분(Bank, kriging)을 넣지 않는다.
    - 앵커별 보정 버전과 앵커 공통 보정 버전(앵커 정체 정보를 쓰지 않음)을 함께 보고한다.
- **3-C:**
  - 다른 환경의 앵커 사전확률 AUC-PR은 0.321–0.807이고, 양성 비율은 0.250–0.752다. 우연 수준(최대 +0.07)이라 앵커 정체를 통한 누수 경로가 거의 없다.
  - 다만 LOS RX−FP 분포가 환경·앵커마다 다르다. 환경 중앙값은 2.85–4.44 dB, 앵커별 중앙값은 2.57–9.28 dB다. 그래서 환경 간 임계값 이전이 어려울 수 있다 (추정).
- **3-D:** LOS 테스트 셀 커버리지가 g = 0에서 0.79–0.98, g = 5에서 0.64–0.98이다. 진행할 수 있다.

**실험 5 (D2) 적용**
- 3-B(주, 위 조건부) + 3-C(강건성) + 3-D(kriging)로 진행하고, 3-A는 제외한다.
- 3-C는 누수 위험이 가장 낮다. 3-C를 주 결과로 올릴지는 실험 5를 사전 등록할 때(모델 결과를 보기 전) 다시 정한다.
- **3-A 재개 조건:** 위치 간격이 넓거나 NLOS가 덜 이어지는 새 데이터에서 같은 사전 점검(이웃 라벨·마스크 부재 ≤ 양성 비율 + 0.05, 커버리지 ≥ 0.5)을 통과할 때.
