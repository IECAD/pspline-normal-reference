## 1. 목적

센서×시간 곡면을 만들 때 **센서 축에 무엇을, 어떤 스케일·순서·구조로 쌓는지**가 탐지와 위치화 성능에 어떤 영향을 주는지 체계적으로 확인하고, 이후 모든 실험에 쓸 기본 합성 방식을 확정한다.

### 답할 질문
| 질문 | 대응 축 |
|---|---|
| Q1. 어떤 변수를 넣어야 하는가 | ① 변수 구성 |
| Q2. 단위가 다른 변수를 어떻게 맞추는가 | ② 스케일링 |
| Q3. 센서 순서가 성능을 바꾸는가 | ③ 순서 |
| Q4. 이질적 지표를 한 곡면에 섞어도 되는가 | ④ 구조 |
| Q5. 센서 방향 평활 자체가 도움이 되는가 | ④ 구조(T4) |

## 2. 배경과 근거 (문헌 조사 요약)

| 축 | 분야 공통 관행 | 핵심 근거 | 설계에 미친 영향 |
|---|---|---|---|
| ① 변수 | 없음 | 센서 조합 효과는 조건부(Shoaib 2014). UWB 지표 간 정보 중복 우려(Savic 2015). RX−FP 추가 효과(Yang 2024) | 조합을 실험으로 보여야 함. 파생 변수·중복 제거 조합 포함 |
| ② 스케일 | 사실상 z-score | autoscaling이 MSPC 관행. z-score가 오히려 성능을 낮춘 사례, robust는 개선(Sarfraz 2024, 단 이상점수 정규화 결과) | robust(S3) 필수 비교 |
| ③ 순서 | 없음 | 상관 변수 인접 배치 시 CNN +5.5%p(Li 2023). 순서 불변 모델에서는 효과 소멸. EEG 상관 정렬 효과 작음(Keelawat 2021) | 무작위 순서 반복으로 민감도 정량화. 그래프 penalty 대안 포함 |
| ④ 구조 | 축별 λ는 표준, 통합 vs 텐서는 미정 | SAP(2015), PS-ANOVA(Lee & Durbán 2011). 통합 vs 텐서 비교 선례(Grasso 2014). 잔차 번짐(Van den Kerkhof 2013). 평활 가정이 틀리면 그래프 정규화 무효(Dabush & Routtenberg) | 통합 곡면을 기본안에서 내리고 지표별 블록을 기본안으로. λ_s→0 기준선 필수 |

**기여 공간**: 순서·번짐 근거는 대부분 CNN 결과다. P-spline 센서 축 평활에서 합성 방식을 체계적으로 실험한 연구는 조사 범위에서 찾지 못했다(“미발견”이지 “없음”이 아님).

## 3. 선택지 정의

★ = 기본안(B0)

### ① 변수 구성
| 코드 | 이름 | 내용 (앵커 4개 기준 행 수) |
|---|---|---|
| V1 | 거리만 | 거리 (4행) |
| V2 | 거리+RX | 거리, RX power (8행) |
| V3 ★ | 거리+RX+FP | 거리, RX power, FP power (12행) |
| V4 | V3+파생 | V3 + (RX − FP) (16행) |
| V5 | 중복 제거 | 거리 + (RX − FP) (8행) |

### ② 스케일링 (모든 통계는 정상 학습 데이터에서만 계산)
| 코드 | 이름 | 내용 |
|---|---|---|
| S0 | 원값 | 정규화 없음 (대조군) |
| S1 ★ | z-score | 센서별 평균·표준편차 |
| S2 | min-max | 센서별 [0, 1] |
| S3 | robust | 센서별 중앙값·IQR |
| S4 | 지표별 가중 | S1 후 지표 블록별 가중(정상 잔차분산의 역수) |

### ③ 센서 순서
| 코드 | 이름 | 내용 |
|---|---|---|
| O1 | 원래 순서 | 앵커 번호 순 |
| O2 ★ | 상관 seriation | d_ij = 1 − \|ρ_ij\|, 계층 군집 leaf 순서 (블록 안에서 적용) |
| O3 | 무작위 | 무작위 순서 10회 반복, 분포로 보고 |
| O4 | 그래프 Laplacian | 순서 대신 상관 그래프 Laplacian을 센서 방향 penalty로 사용 |

### ④ 곡면 구조
| 코드 | 이름 | 내용 |
|---|---|---|
| T1 | 통합 곡면 | 모든 지표를 한 센서 축에 쌓고 연속 평활 |
| T2 ★ | 지표별 블록 | 지표별 블록, 블록 내 평활, 블록 경계 penalty 차단 |
| T3 | 3D 텐서 | 앵커×지표×시간, 모드별 λ |
| T4 | 센서 평활 끔 | λ_s → 0 (센서별 독립 1D P-spline). 순서 무관 |

### 공통 고정 사항
- λ_s, λ_t: SAP(REML)로 자동 추정 (모든 실험 동일 절차)
- 차분: 2차
- 이상점수: A_R(표준화 잔차)만 사용. 보조 점수(A_K, A_C)는 실험 4에서 따로 다룸
- 윈도우 길이, 임계 백분위(97.5%): 모든 실험 동일

## 6. 선택 규칙 (F01 구성 방법, 결과를 보기 전에 고정)

1. **판정 기준 지표**: 검증 세트 AUC-PR
2. **동률 판정**: 두 선택지 차이가 B0 반복 실행 표준편차(또는 0.01) 이내면 동률
3. **동률일 때 우선순위**: HitRate@100% → Smearing 비율(낮을수록) → 더 단순한 선택지
   - 단순함 순서: V1 < V5 < V2 < V3 < V4 / S1 < S2 < S3 < S4 < S0 제외 / O1 < O2 < O4 / T4 < T2 < T1 < T3
4. **테스트 세트는 선택에 쓰지 않는다.** F01, F02 확정 후 테스트 결과를 한 번만 보고한다.
5. 축 간 상호작용(3단계)에서 2단계와 반대 결론이 나오면, 상호작용 결과를 따르고 그 사실을 보고한다.

## 7. 실행 규칙

- 분할: 시간 순서 유지(학습 → 검증 → 테스트). 무작위 셔플 금지
- 스케일·순서·임계값 계산: 정상 학습/검증 데이터만 사용
- seriation 순서는 학습 데이터에서 한 번 정하고 고정
- 무작위 순서(O3): 시드 0~9 고정, 평균±표준편차와 최솟값·최댓값 보고
- 모든 실행은 config(V/S/O/T 코드, 시드, 데이터 버전)와 함께 `results/E##/`에 저장
- 금지: point-adjust F1, 정확도 단독 보고, 테스트 결과를 보고 선택지 바꾸기
