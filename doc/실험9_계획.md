# 실험 9 계획: 범용성 — D4 서버 데이터 (사전 등록)

작성: 2026-10-11 · 상위: `doc/PROJECT_BRIEF.md` 5.2절 실험 9 (RQ7: UWB 외 다변량 데이터에도 적용되는가) · 대상: 이 저장소에서 작업하는 사람과 AI 어시스턴트

## 0. 배경과 질문
- 실험 3에서 D4의 절대 성능은 낮았다 (SMD AUC-PR 0.37, ASD 0.18, `results/exp3/report.md` 4.4절).
  - 그때는 비교 모델이 없었다. 이번에는 비교 모델과 함께 본다 (실험 1·2 축소 반복).
- D4에는 "위치(노드)"가 없다. 엔터티(서버)마다 노드가 하나이고, 정상 곡면은 윈도우 안 시점별 평균 모양이 된다. 서버 지표는 윈도우 위상과 무관하게 변한다.
  - 그래서 이 실험은 "노드별 반복 정상 패턴이 없는 데이터에서도 쓸 수 있는가"를 묻는다.

## 1. 구성
- **데이터:** SMD 28대, ASD 12개. 분할은 단계 1 그대로다. 공식 train의 앞부분 = 학습, 뒷부분 = 검증(라벨 없음), 공식 test = 테스트.
- **합성:** ②③④축만 (S1·O1·T4, 실험 3의 D4 처리와 같음). T = 12.
- **평가:** 실험 3 `run_d4`와 같다.
  - 테스트 윈도우를 시간순으로 이어 붙인다.
  - 탐지 = 시점 AUC-PR (점 라벨 lab_P).
  - 위치화 = HitRate, 셀 F1, Smearing (해석 라벨 lab_I, 변수 단위).
- **모델:**
  - PS (K_t = T, SAP), 셀 평균(M01), 노드 평균(Z1)
  - PCA, OLS, Isolation Forest, LSTM-AE, USAD, 1D-CAE, GDN(재구현), Transformer(시점 마스킹)
- **구성 선택 규칙 (D4는 검증 라벨이 없음):**
  - 각 비교 모델은 실험 1에서 **D2에 고른 구성**을 쓴다 (D2가 센서 수가 많아 가장 가깝다). 입력은 raw로 고정한다. 노드가 하나라 nc는 위상 평균을 뺀 것에 불과하다.
  - 셀 점수·임계 규칙은 실험 1과 같다 (|오차| / 행별 검증 SD, 검증 97.5 백분위).
  - PS는 튜닝이 없다.
- **뺀 모델:**
  - OmniAnomaly: 엔터티 40개 × 학습 윈도우 최대 약 1,800개에서 학습 시간이 너무 길다 (D1 강의실 구성 하나에 약 3분). SMD의 원 방법이고 공개 결과가 있지만, 그 결과는 point-adjust F1이라 직접 비교할 수 없다.
  - RPCA류·RRR·2D Conv-AE: 축소 반복이라 각 계열 대표만 남겼다.

## 2. 판정
- 데이터(SMD, ASD)마다 PS − 모델의 엔터티 짝지은 AUC-PR Δ를 본다. 허용오차는 0.0171 (D2 값을 따름).
  - 우위: Δ > tol, 대등: |Δ| ≤ tol, 열세: Δ < −tol.
- **RQ7 답 (미리 정함):**
  - 두 데이터 모두에서 PS가 비교 모델(셀 평균·노드 평균 제외 8개)의 과반에 대해 대등 이상이면: "UWB 밖 다변량 데이터에도 경쟁력 있게 적용된다."
  - 한 데이터만 그렇다면: "제한적으로 적용된다."
  - 둘 다 아니면: "**적용 범위 밖이다.** 위치별 반복 정상 패턴이 있는 데이터에 한정된다."
- 위치화(HitRate)는 같은 방식으로 서술만 한다.

- **(2026-10-12 수정, 실행 중, 문헌 대조 후)** 1부 실행(PS·셀 평균·노드 평균 + 1차 비교 모델 6개)은 끝났다. 1부 결과는 아직 보지 않았다.
  - USAD는 학습 오류판이었다 (`doc/문헌대조_결과.md` #1). 그래서 판정용 비교 모델을 **USADFIX2**(원형 출력 Sigmoid 포함, `doc/실험1_비교모델_계획.md` "추가 수정")로 바꾼다. 1부의 USAD 행과 2부의 USADFIX 행은 기록으로만 남긴다.
  - GDN은 수정판을 쓴다 (#5).
  - 구성은 `results/exp1_baselines/batch2_fix/`의 D2 선택이다.

## 3. 실행 전 예상 (추정)
- PS는 대부분의 비교 모델(PCA, OLS, LSTM-AE, USAD, GDN)보다 낮을 것이다. 서버 지표는 시점 간 의존과 변수 간 상관이 정보의 대부분이고, 윈도우 위상 평균 모양은 정보가 적다.
- 따라서 RQ7은 "적용 범위 밖"일 가능성이 크다. 그 경우 BRIEF 기여에서 범용성 주장을 빼고 적용 조건(위치별 반복 정상 데이터)을 명시한다.
- PS ≈ 셀 평균 ≈ 노드 평균일 것이다.
- 출력: `results/exp9/`

## 결과 (2026-10-12, 규칙 적용 후 덧붙임)
- **RQ7: "적용 범위 밖".** PS가 열세가 아닌 비교 모델은 SMD 3/8, ASD 1/8이다.
- 탐지(AUC-PR): PS는 LSTM-AE·1D-CAE·PCA·Transformer·OLS보다 낮다 (SMD −0.03 ~ −0.07, ASD −0.16 ~ −0.22).
- 위치화(HitRate): PS가 두 데이터 모두 최상위권이고, Smearing은 가장 낮은 축이다.
