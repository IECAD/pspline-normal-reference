# 실험 4 보고서: 구성요소 ablation → 최종 모델 (C00–C15, M01–M02) + 실험 1 단순 기준선 테스트

작성: 2026-10-10 · 대상: 이 저장소에서 작업하는 사람과 AI 어시스턴트 · 계획(사전 등록): `doc/실험4_계획.md` · 상위: `doc/PROJECT_BRIEF.md`, `doc/결정기록_실험3이후.md`

## 0. 요약

- **최종 모델 = M01 = F01 + 셀 평균 시간 기저.** 정상 기준은 노드×행×시간 평균(λ_t = 0 극한)이고, 시간 방향 P-spline 평활은 없다. 실험 1 단순 기준선 Z2와 같은 구성이다.
- **이 선택은 데이터가 아니라 동률 규칙으로 정해졌다.**
  - 시간 기저 축에서 F01을 "이긴" 후보는 K10, K12, adaptive, 셀 평균 네 개였다. 이들은 평균 Δ, HitRate, Smearing에서 모두 동률이었다.
  - 그래서 사전 등록한 단순함 순서(상수 < 셀 평균 < K10 < K12 < adaptive)로 셀 평균이 됐다.
  - 검증 평균 Δ는 K12가 +0.0096, 셀 평균이 +0.0061로 K12가 약간 높았다 (동률 범위 0.0165 안).
  - 테스트에서도 둘은 구분되지 않는다: D2 다지표 K12 +0.0150, 셀 평균 +0.0146.
- **차분 차수, λ 모드(행별 SAP·수동)는 F01을 이기지 못했다.** 큰 수동 λ_t(≥ 10)는 D2에서 크게 나쁘다.
- **보조 점수 A_K·A_C는 검증 주입 평가에서 0.08–0.13 낮다.** 기본안에 넣지 않는다 (BRIEF 6절 6번 답).
- **테스트 (선택 확정 후 한 번), 최종 M01 − F01 짝지은 ΔAUC-PR:** D1 주입 +0.0013, D2 다지표 +0.0146 (양수 0.83), D2 거리만 −0.0009.
- **실험 1 단순 기준선 (테스트):** F01 − Z1(D1) = −0.0002 대등, F01 − Z2(D2) = −0.0146 대등. 최종 M01은 D1에서 Z1과 대등하고(+0.0011), D2에서는 Z2와 같은 구성이다.
  - → `doc/결정기록_실험3이후.md` 2절 조정표의 **"대등" 경로**를 적용한다 (6절).

## 2. 선택 (검증, `results/exp4/selection.json`)

짝지은 ΔAUC-PR = 같은 공간·시나리오·시드끼리 C00과 비교. "이김" = 한 데이터 이상에서 Δ > tol, 두 데이터 모두 Δ ≥ −tol (tol D1 0.0165, D2 0.0171).

| | C03 K12 | +0.0000 | +0.0191 | +0.0096 | ✔ | |
| | C04 adaptive (D1 K = 5, D2 K = 12) | −0.0000 | +0.0191 | +0.0096 | ✔ | |
| ⓒ λ_t | C08–C12 수동 1e-3 / 1e-1 / 1e1 / 1e3 / 1e5 | −0.002 ~ +0.000 | +0.001 / −0.009 / −0.075 / −0.165 / −0.169 | | ✘ | **현재값 (SAP 공유)** |

- 시간 기저 축의 동률 사슬: 이긴 4개의 평균 Δ 차이 0.0035 < 0.0165 → HitRate 0.9835–0.9849 (차이 < 0.01) → Smearing 0.0705–0.0733 (차이 < 0.01) → 단순함 순서로 C06.
- M01 = {time_basis: cell}. 셀 평균이라 ⓐ·ⓒ 축은 무관하다.
- M02 = 차선 결합 = {diff_order: 1, K_t: 10, lam_mode: sap_row}.
- 상호작용 확인: 단독 구성(C06)이 M01을 이기지 않음 (같은 구성) → **최종 M01**.

## 6. 해석과 주장 조정 (사전 등록 조정표 "대등" 경로)

1. **"P-spline 정상 곡면이 단순 기준선보다 낫다"는 주장할 수 없다.**
   - 정지 측정(D1)에서는 노드별 평균과 대등하다.
   - 반복 측정(D2)에서는 위치별 평균과 대등하거나 약간 낮다.
   - 최종 모델 자체가 평활 없는 셀 평균이다.
2. **기여 2는 "노드별 정상 모델 + 닫힌 형태 표준화 잔차로 탐지와 앵커·시간 위치화를 함께 제공하는 경량 프레임워크"로 낮춘다.**
   - P-spline은 이 프레임워크의 일반형으로 남는다. 셀 평균은 λ_t = 0, 노드 평균은 1차 차분 λ_t → ∞의 특수한 경우다.
   - 데이터로는 셀 평균과 K12 P-spline을 구분할 수 없다 (2절, 4.1절).
3. **방법 고유의 근거는 실험 5(미학습 위치 kriging, 3-D)와 실험 7(측위)로 옮긴다.**
   - 미학습 위치에서는 위치별 평균을 직접 쓸 수 없어, 기준 곡면을 보간하는 방식의 차이가 드러날 수 있다 (추정).
4. **제목·한 줄 정의의 "P-spline 정상 곡면"은 다시 검토해야 한다 (사용자 결정 필요).** BRIEF에는 "결정 대기"로 적었다.
5. 보조 점수(A_K, A_C)는 기본안에서 뺀다. BRIEF 2.5절의 초안 정의는 구현(`bank.py`)과 함께 남긴다.
6. 주입 과제의 쉬움: D1 Lab·복도는 천장 효과가 있다 (실험 3 보고서 7절 4번). 단순 기준선과 대등하다는 결과는 이 과제 조건에서의 결론이다.

## 7. 열어 두는 것

- **셀 평균 vs P-spline (K12):** 실험 5 미학습 위치(3-D, D1 복도 10점)에서 둘을 함께 비교한다. 실험 5 사전 등록 때 판정 기준을 적는다. 거기서 P-spline이 사전 기준으로 이기면 기본안 교체를 다시 검토한다.
- **보조 점수 A_C:** 강의실 실제 NLOS에서 높았던 관찰(4.2절)은 테스트에서만 본 것이다. 새 측정(BRIEF 4.2절, 같은 날 LOS → NLOS)에서 검증용 실제 NLOS가 생기면 사전 등록 후 다시 시험한다.
- **D3 (이동 궤적):** 시간 축이 실제 시간이고 위치가 변하므로 셀 평균(노드 = 녹화)은 의미가 없다. D3를 다루면 모델 정의를 실행 전에 다시 정한다 (결정기록 2절).
- 모든 구성(C00–C15)의 구현과 설정은 그대로 둔다.

## 8. 한계

- 판정 데이터는 인공 주입이다. D1은 거리만, D2는 실제 NLOS 서명을 재표본한 주입이다. 실제 NLOS 평가는 실험 5의 3-B·3-C에서 한다.
- D1 테스트 윈도우가 적다 (정상 파일 테스트 몫 48–60개, 단계 1 보고서 5절).

- VUS-PR, Range-F1은 이 저장소 구현이다 (`src/metrics/anomaly.py`).
