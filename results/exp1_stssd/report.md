# 실험 1 보고서: ST-SSD형 (정적) vs 제안 모델 PS

작성: 2026-10-11 · 계획(사전 등록): `doc/실험1_ST-SSD_계획.md` · 코드: `src/model/stssd.py`, `experiments/exp1_stssd.py`, `exp1_stssd_summarize.py` · 결과: `metrics_search_*`, `metrics_test_*`, `selection.json`, `summary.md`, `paired.csv`

## 0. 요약
> **2026-10-12 갱신 (원 논문 대조 후, `doc/실험1_ST-SSD_계획.md` "원 논문 대조", `doc/문헌대조_결과.md` #6):**
> - 이 기준선은 원 논문 4.3절(정상 과정)의 이상 분해와 일치한다. 원형의 감시 통계량(다중 γ LRT)과 동적 평균은 구현하지 않았다.
> - 항등 기저에서 |S_{γ/2}(z)|는 |z|의 단조변환이라 셀 AUC-PR은 구조적으로 γ = 0에서 가장 높다. 그래서 선택된 구성은 희소 분해가 꺼진 |z| 점수다. **"PS ≈ N"은 같은 배경과 같은 점수라 거의 동어반복이고, 희소 분해의 효과를 시험한 결과로 쓰지 않는다.**
> - 원형 비교는 사전 등록한 변형 R(다중 γ LRT)·D(동적 평균)로 한다.

- **구현 한계:** 원 논문 Algorithm 원문을 확인하지 못해, 공개 요약의 구조로 만든 "ST-SSD형" 기준선이다 (계획 0절).
- **검증 탐색:** 세 변형 모두에서 γ = 0, 항등 기저(희소화 없음)가 가장 좋았다.
  - 희소 분해(γ > 0)와 매끄러운 이상 기저(K_a = 6)는 성능을 낮추기만 했다. 예: N 변형 D1에서 K_a = 6이면 γ = 0에서도 0.911 (항등 0.970).
- **테스트 판정 (PS − 모델, 허용오차 D1 0.0165 · D2 0.0171)**

  | 모델 | D1 AUC-PR | D2 AUC-PR | PS − 모델 D1 / D2 | 판정 |
  |---|---|---|---|---|
  | PS (제안) | 0.935 | 0.904 | — | — |
  | G1 (원형에 가까움: 전역 배경, O1) | 0.343 | 0.487 | +0.592 / +0.417 | **PS 우위** |
  | G2 (전역 배경, seriation O2) | 0.343 | 0.486 | +0.592 / +0.418 | **PS 우위** |
  | N (노드별 배경 + ST-SSD형 점수) | 0.935 | 0.904 | +0.000 / −0.000 | 대등 |

- **해석:**
  - PS의 우위는 전적으로 **노드별 정상 배경(Bank)** 에서 나온다. 점수 방식의 차이에서 나온 것이 아니다.
  - 희소 분해 + 우도비형 점수는 이 과제에서 이득이 없었다. 선택된 구성이 희소화를 끈 것이라, N은 사실상 PS와 같은 모델이 된다.
- seriation 전·후(G1 vs G2)는 차이가 없다 (D1 동일, D2 0.001). 실험 3과 같은 결론이다.

## 1. 계산 비용 (PC, 단일 스레드, 윈도우당 추론 ms)
- PS 0.0034 (D1) / 0.0027 (D2). 선택된 ST-SSD형은 항등 기저라 0.0013–0.0039로 비슷하다.
- 희소 분해를 FISTA로 푸는 구성(K_a = 6)은 D1에서 0.14 ms로, PS의 약 40배였다 (검증 탐색 중 측정). 이 구성은 성능도 낮았다.

## 2. 한계
- 원형과의 차이가 있을 수 있다: 배경 λ 선택(여기서는 SAP), 이상 기저, 검정 통계량 형태, 재귀 추정. 원 논문 PDF로 Algorithm을 대조해야 한다.
- 원형 ST-SSD는 "위치마다 정상 패턴이 다른" UWB 노드 구조를 가정하지 않는다. 그래서 G1·G2의 낮은 성능은 방법의 결함이라기보다 **문제 설정의 차이**다. 논문에서는 이 점을 함께 써야 공정하다.
- 비교는 주입 평가다. 실제 NLOS(D2 3-B·3-C)로는 비교하지 않았다.

## 3. 원형 변형 결과 (2026-10-12, `results/exp1_stssd/original/summary.md`)
- 원 논문 대조 후 사전 등록한 변형 R(원형 감시 통계량, 식 12)·D(동적 평균, 4.2절)와 사후 탐색 D′를 테스트에서 한 번 돌렸다.
- **셀 AUC-PR은 모든 변형에서 PS 우위다.**
  - R + 노드별 배경: D1 +0.087, D2 +0.117
  - D′: D1 +0.060
  - 전역 배경 계열: +0.43 이상
- **윈도우 단위 탐지에서는 원형 통계량 + 노드별 배경이 D2에서 PS보다 높다** (0.963 대 0.928). D1에서는 같다.
  - 윈도우 안 증거를 합치는 LRT가 셀 최댓값보다 윈도우 탐지에 유리하다 (추정).
  - 그래서 논문에는 "셀 단위 위치화는 PS가 낫고, 윈도우 단위 탐지는 원형 통계량을 노드별 배경 위에 얹으면 같거나 낫다"고 쓴다.
- 동적 평균은 위치 라벨 없이 같은 위치에 머무는 동안 적응할 수 있다 (D′ D1 0.876). 위치가 계속 바뀌는 D2 경로에서는 효과가 없다.
