# 실험 9 보고서: 범용성 — D4 서버 데이터 (RQ7)

작성: 2026-10-12 · 계획(사전 등록): `doc/실험9_계획.md` · 코드: `experiments/exp9_d4.py`, `exp9_summarize.py` · 결과: `metrics_<데이터>_part{1,2,3}.csv`, `summary.md`, `paired.csv`, `decision.json`

## 0. 요약 (테스트, 엔터티 짝지은 AUC-PR, 허용오차 0.0171)
- **RQ7 판정: "적용 범위 밖" (사전 규칙 그대로, 사전 예상과 같음).**
  - PS가 열세가 아닌 비교 모델은 SMD 3/8, ASD 1/8이다. 과반 기준(5/8)에 두 데이터 모두 못 미친다.
- **탐지 (AUC-PR):**
  - SMD: PS 0.365. LSTM-AE 0.429, 1D-CAE 0.433, PCA 0.427, Transformer 0.420, OLS 0.390보다 낮다 (−0.03 ~ −0.07). GDN 0.359와는 대등하다.
  - ASD: PS 0.178. LSTM-AE 0.394, Transformer 0.377 등 대부분보다 크게 낮다 (−0.16 ~ −0.22).
- **위치화 (HitRate@100 %, 변수 단위 해석 라벨):** PS가 두 데이터 모두 최상위권이다.
  - SMD: PS 0.486, OLS 0.434, LSTM-AE 0.415
  - ASD: PS 0.645, USAD 계열 0.63, LSTM-AE 0.622
  - Smearing도 가장 낮은 축이다 (SMD 0.40 vs 0.48–0.63).
- **PS = 셀 평균 = 노드 평균:** 엔터티마다 노드가 하나라 평활할 위치 구조가 없다.
- USAD 원형 수정판은 D4에서 크게 낮다 (SMD 0.135). 학습 몫 min-max로 정규화하므로, 테스트 값이 그 범위를 벗어나면 Sigmoid 출력이 포화되는 것으로 보인다 (추정). 원 논문도 같은 정규화를 쓴다.

## 1. 해석
1. 이 방법의 정상 모델은 "위치(노드)마다 반복되는 정상 패턴"을 학습한다. 서버 지표처럼 위치 구조가 없고 시점 간 의존과 변수 간 상관이 정보의 대부분인 데이터에서는, 시간·변수 구조를 쓰는 모델보다 탐지가 약하다.
2. 그래도 행(변수) 독립 표준화 잔차라서 이상 변수의 순위(위치화)는 번짐이 적고 정확하다. 이 성질은 데이터와 무관하게 유지된다.
3. **논문 주장:**
   - 범용성(RQ7)은 주장하지 않는다.
   - 적용 조건을 "위치별 반복 정상 데이터가 있는 다변량 센서(측위 앵커 등)"로 명시한다.
   - "변수 단위 위치화의 번짐이 적다"는 성질만 D4에서도 확인됐다고 쓴다.

## 2. 한계
- 비교 모델 구성은 D2 선택을 그대로 썼다 (D4는 검증 라벨이 없음). 모델마다 D4에 맞춰 튜닝하면 차이는 더 커질 수 있다 (추정).
- OmniAnomaly는 계산 비용 때문에 뺐다. SMD의 원 방법이지만 공개 수치는 point-adjust F1이라 비교하지 않는다.
- 1부의 USAD(학습 오류판)와 2부의 USADFIX(발산판)는 기록용이고 판정에 넣지 않았다.
